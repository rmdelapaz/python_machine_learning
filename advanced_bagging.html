Introduction

Bagging (Bootstrap Aggregating) is an ensemble method that combines multiple versions of a predictor to reduce variance and prevent overfitting. By training multiple models on different bootstrap samples of the data and aggregating their predictions, bagging creates more stable and robust models. This lesson covers the theory behind bagging, implementation details, Random Forests as an extension of bagging, and practical applications.

Implementing Bagging from Scratch

class BaggingFromScratch:
    """
    Bagging implementation from scratch
    """
    
    def __init__(self, base_estimator, n_estimators=10, max_samples=1.0, 
                 max_features=1.0, bootstrap=True, random_state=None):
        """
        Initialize bagging ensemble
        
        Parameters:
        -----------
        base_estimator : object
            Base estimator to use
        n_estimators : int
            Number of estimators in ensemble
        max_samples : float
            Fraction of samples to use for each estimator
        max_features : float
            Fraction of features to use for each estimator
        bootstrap : bool
            Whether to use bootstrap sampling
        """
        self.base_estimator = base_estimator
        self.n_estimators = n_estimators
        self.max_samples = max_samples
        self.max_features = max_features
        self.bootstrap = bootstrap
        self.random_state = random_state
        self.estimators_ = []
        self.feature_indices_ = []
        
        if random_state is not None:
            np.random.seed(random_state)
    
    def _bootstrap_sample(self, X, y):
        """Create bootstrap sample"""
        n_samples = X.shape[0]
        sample_size = int(self.max_samples * n_samples)
        
        if self.bootstrap:
            # Sample with replacement
            indices = np.random.choice(n_samples, size=sample_size, replace=True)
        else:
            # Sample without replacement
            indices = np.random.choice(n_samples, size=sample_size, replace=False)
        
        return X[indices], y[indices], indices
    
    def _random_feature_subset(self, n_features):
        """Select random subset of features"""
        feature_size = int(self.max_features * n_features)
        feature_indices = np.random.choice(n_features, size=feature_size, replace=False)
        return sorted(feature_indices)
    
    def fit(self, X, y):
        """
        Train bagging ensemble
        """
        n_samples, n_features = X.shape
        
        for i in range(self.n_estimators):
            # Create bootstrap sample
            X_sample, y_sample, sample_indices = self._bootstrap_sample(X, y)
            
            # Select random features
            feature_indices = self._random_feature_subset(n_features)
            self.feature_indices_.append(feature_indices)
            
            # Select feature subset
            X_sample = X_sample[:, feature_indices]
            
            # Train base estimator
            estimator = self.base_estimator.__class__(**self.base_estimator.get_params())
            estimator.fit(X_sample, y_sample)
            
            self.estimators_.append(estimator)
            
        return self
    
    def predict(self, X):
        """
        Make predictions using ensemble
        """
        # Collect predictions from all estimators
        predictions = []
        
        for estimator, feature_indices in zip(self.estimators_, self.feature_indices_):
            # Use only selected features
            X_subset = X[:, feature_indices]
            pred = estimator.predict(X_subset)
            predictions.append(pred)
        
        # Aggregate predictions
        predictions = np.array(predictions)
        
        # For classification: majority voting
        # For regression: averaging
        if hasattr(self.base_estimator, 'predict_proba'):
            # Classification - majority voting
            from scipy import stats
            final_predictions = stats.mode(predictions, axis=0)[0].flatten()
        else:
            # Regression - averaging
            final_predictions = np.mean(predictions, axis=0)
        
        return final_predictions
    
    def predict_proba(self, X):
        """
        Predict class probabilities (for classification)
        """
        if not hasattr(self.base_estimator, 'predict_proba'):
            raise AttributeError("Base estimator doesn't support probability prediction")
        
        # Collect probability predictions
        probas = []
        
        for estimator, feature_indices in zip(self.estimators_, self.feature_indices_):
            X_subset = X[:, feature_indices]
            proba = estimator.predict_proba(X_subset)
            probas.append(proba)
        
        # Average probabilities
        return np.mean(probas, axis=0)
    
    def score(self, X, y):
        """
        Calculate accuracy score
        """
        predictions = self.predict(X)
        if hasattr(self.base_estimator, 'predict_proba'):
            return accuracy_score(y, predictions)
        else:
            return -mean_squared_error(y, predictions)

def compare_bagging_parameters():
    """
    Compare different bagging parameters
    """
    # Load dataset
    data = load_breast_cancer()
    X, y = data.data, data.target
    
    # Split data
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
    
    # Standardize features
    scaler = StandardScaler()
    X_train = scaler.fit_transform(X_train)
    X_test = scaler.transform(X_test)
    
    # Different bagging configurations
    configs = [
        {'n_estimators': 10, 'max_samples': 1.0, 'max_features': 1.0},
        {'n_estimators': 50, 'max_samples': 1.0, 'max_features': 1.0},
        {'n_estimators': 50, 'max_samples': 0.7, 'max_features': 1.0},
        {'n_estimators': 50, 'max_samples': 0.7, 'max_features': 0.7},
    ]
    
    results = []
    
    for config in configs:
        # Create bagging classifier
        bagging = BaggingClassifier(
            base_estimator=DecisionTreeClassifier(max_depth=5),
            **config,
            random_state=42,
            n_jobs=-1
        )
        
        # Train
        bagging.fit(X_train, y_train)
        
        # Evaluate
        train_score = bagging.score(X_train, y_train)
        test_score = bagging.score(X_test, y_test)
        
        # Cross-validation
        cv_scores = cross_val_score(bagging, X_train, y_train, cv=5)
        
        results.append({
            'config': config,
            'train_score': train_score,
            'test_score': test_score,
            'cv_mean': cv_scores.mean(),
            'cv_std': cv_scores.std()
        })
        
        print(f"\nConfig: {config}")
        print(f"Train Score: {train_score:.4f}")
        print(f"Test Score: {test_score:.4f}")
        print(f"CV Score: {cv_scores.mean():.4f} (+/- {cv_scores.std():.4f})")
    
    return results

class OOBAnalysis:
    """
    Out-of-Bag score analysis
    """
    
    def demonstrate_oob(self, X, y):
        """
        Demonstrate OOB scoring
        """
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=0.3, random_state=42
        )
        
        # Bagging with OOB score
        bagging_oob = BaggingClassifier(
            base_estimator=DecisionTreeClassifier(max_depth=5),
            n_estimators=100,
            oob_score=True,  # Enable OOB scoring
            random_state=42,
            n_jobs=-1
        )
        
        # Train
        bagging_oob.fit(X_train, y_train)
        
        # Get scores
        test_score = bagging_oob.score(X_test, y_test)
        oob_score = bagging_oob.oob_score_
        
        print("\n" + "=" * 50)
        print("OUT-OF-BAG (OOB) SCORING")
        print("=" * 50)
        print(f"OOB Score: {oob_score:.4f}")
        print(f"Test Score: {test_score:.4f}")
        print(f"Difference: {abs(oob_score - test_score):.4f}")
        
        # Get OOB predictions
        oob_predictions = bagging_oob.oob_decision_function_
        
        # Visualize OOB predictions confidence
        fig, axes = plt.subplots(1, 2, figsize=(12, 5))
        
        # Plot 1: OOB prediction confidence distribution
        axes[0].hist(oob_predictions[:, 1], bins=30, alpha=0.7, edgecolor='black')
        axes[0].set_xlabel('OOB Prediction Confidence (Class 1)')
        axes[0].set_ylabel('Frequency')
        axes[0].set_title('OOB Prediction Confidence Distribution')
        axes[0].grid(True, alpha=0.3)
        
        # Plot 2: OOB vs actual predictions
        test_predictions = bagging_oob.predict_proba(X_test)[:, 1]
        axes[1].scatter(test_predictions, bagging_oob.predict_proba(X_test)[:, 1], 
                       alpha=0.5, s=20)
        axes[1].plot([0, 1], [0, 1], 'r--', label='Perfect Agreement')
        axes[1].set_xlabel('Test Predictions')
        axes[1].set_ylabel('Model Predictions')
        axes[1].set_title('Prediction Consistency')
        axes[1].legend()
        axes[1].grid(True, alpha=0.3)
        
        plt.suptitle('Out-of-Bag Analysis', fontsize=14)
        plt.tight_layout()
        plt.show()
        
        return oob_score, test_score
    
    def oob_feature_importance(self, X, y, feature_names=None):
        """
        Calculate feature importance using OOB samples
        """
        if feature_names is None:
            feature_names = [f'Feature_{i}' for i in range(X.shape[1])]
        
        # Train bagging with OOB
        bagging = BaggingClassifier(
            base_estimator=DecisionTreeClassifier(max_depth=5),
            n_estimators=100,
            oob_score=True,
            random_state=42
        )
        bagging.fit(X, y)
        
        baseline_oob = bagging.oob_score_
        
        # Calculate permutation importance using OOB
        importance_scores = []
        
        for i in range(X.shape[1]):
            # Permute feature i
            X_permuted = X.copy()
            np.random.shuffle(X_permuted[:, i])
            
            # Retrain and get OOB score
            bagging_permuted = BaggingClassifier(
                base_estimator=DecisionTreeClassifier(max_depth=5),
                n_estimators=100,
                oob_score=True,
                random_state=42
            )
            bagging_permuted.fit(X_permuted, y)
            
            # Calculate importance as drop in OOB score
            importance = baseline_oob - bagging_permuted.oob_score_
            importance_scores.append(importance)
        
        # Create importance DataFrame
        importance_df = pd.DataFrame({
            'feature': feature_names,
            'importance': importance_scores
        }).sort_values('importance', ascending=False)
        
        # Visualize
        plt.figure(figsize=(10, 6))
        plt.barh(range(min(15, len(importance_df))), 
                importance_df['importance'].head(15))
        plt.yticks(range(min(15, len(importance_df))), 
                  importance_df['feature'].head(15))
        plt.xlabel('Importance (OOB Score Drop)')
        plt.title('Feature Importance from OOB Permutation')
        plt.gca().invert_yaxis()
        plt.grid(True, alpha=0.3)
        plt.tight_layout()
        plt.show()
        
        return importance_df

def random_forest_analysis():
    """
    Analyze Random Forest as an enhanced bagging method
    """
    # Generate data
    X, y = make_classification(n_samples=1000, n_features=20, 
                              n_informative=15, n_redundant=5,
                              random_state=42)
    
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.3, random_state=42
    )
    
    # Compare models
    models = {
        'Single Tree': DecisionTreeClassifier(max_depth=10, random_state=42),
        'Bagging': BaggingClassifier(
            DecisionTreeClassifier(max_depth=10),
            n_estimators=50,
            random_state=42
        ),
        'Random Forest': RandomForestClassifier(
            n_estimators=50,
            max_depth=10,
            random_state=42
        )
    }
    
    results = {}
    predictions = {}
    
    for name, model in models.items():
        # Train
        model.fit(X_train, y_train)
        
        # Predict
        y_pred = model.predict(X_test)
        predictions[name] = y_pred
        
        # Evaluate
        train_score = model.score(X_train, y_train)
        test_score = model.score(X_test, y_test)
        
        results[name] = {
            'train_score': train_score,
            'test_score': test_score,
            'overfit_gap': train_score - test_score
        }
        
        print(f"\n{name}:")
        print(f"  Train Score: {train_score:.4f}")
        print(f"  Test Score: {test_score:.4f}")
        print(f"  Overfitting Gap: {train_score - test_score:.4f}")
    
    # Visualize comparison
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))
    
    # Plot 1: Score comparison
    models_names = list(results.keys())
    train_scores = [results[m]['train_score'] for m in models_names]

    axes[0].set_ylabel('Accuracy')
    axes[0].set_title('Model Performance Comparison')
    axes[0].set_xticks(x)
    axes[0].set_xticklabels(models_names, rotation=45)
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)
    
    # Plot 2: Overfitting comparison

    axes[1].set_xlabel('Model')
    axes[1].set_ylabel('Train-Test Gap')
    axes[1].set_title('Overfitting Analysis')
    axes[1].tick_params(axis='x', rotation=45)
    axes[1].grid(True, alpha=0.3)
    
    # Plot 3: Feature importance (Random Forest)

    axes[2].set_xticklabels(indices)
    axes[2].grid(True, alpha=0.3)
    
    plt.suptitle('Random Forest vs Bagging vs Single Tree', fontsize=14)

    return results

def variance_reduction_analysis():
    """
    Analyze how bagging reduces variance
    """
    # Generate noisy data
    np.random.seed(42)
    X = np.random.randn(300, 2)
    y = (X[:, 0]**2 + X[:, 1]**2 > 1.5).astype(int)
    
    # Add noise
    noise_idx = np.random.choice(300, 30, replace=False)
    y[noise_idx] = 1 - y[noise_idx]
    
    # Create different models
    models = [
        ('Single Tree (depth=3)', DecisionTreeClassifier(max_depth=3)),
        ('Single Tree (depth=10)', DecisionTreeClassifier(max_depth=10)),
        ('Bagging (depth=3)', BaggingClassifier(DecisionTreeClassifier(max_depth=3), n_estimators=50)),
        ('Bagging (depth=10)', BaggingClassifier(DecisionTreeClassifier(max_depth=10), n_estimators=50))
    ]
    
    # Create mesh for decision boundary
    h = 0.02
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h),
                        np.arange(y_min, y_max, h))
    
    # Plot decision boundaries
    fig, axes = plt.subplots(2, 2, figsize=(12, 10))
    axes = axes.ravel()
    
    for idx, (name, model) in enumerate(models):
        # Train model
        model.fit(X, y)
        
        # Predict on mesh
        Z = model.predict(np.c_[xx.ravel(), yy.ravel()])
        Z = Z.reshape(xx.shape)
        
        # Plot
        axes[idx].contourf(xx, yy, Z, alpha=0.3, cmap='coolwarm')
        axes[idx].scatter(X[:, 0], X[:, 1], c=y, cmap='coolwarm', 
                         edgecolor='black', linewidth=0.5, s=30)
        axes[idx].set_title(f'{name}')
        axes[idx].set_xlabel('Feature 1')
        axes[idx].set_ylabel('Feature 2')
        axes[idx].grid(True, alpha=0.3)
    
    plt.suptitle('Decision Boundaries: Single Tree vs Bagging', fontsize=14)
    plt.tight_layout()
    plt.show()
    
    # Calculate variance across multiple runs
    print("\n" + "=" * 50)
    print("VARIANCE ANALYSIS ACROSS MULTIPLE RUNS")
    print("=" * 50)
    
    n_runs = 20
    test_size = 100
    X_test = np.random.randn(test_size, 2)
    y_test = (X_test[:, 0]**2 + X_test[:, 1]**2 > 1.5).astype(int)
    
    for name, base_model in [('Single Tree', DecisionTreeClassifier(max_depth=10)),
                             ('Bagging', BaggingClassifier(DecisionTreeClassifier(max_depth=10), n_estimators=50))]:
        predictions = []
        
        for run in range(n_runs):
            # Generate new training data
            X_train = np.random.randn(200, 2)
            y_train = (X_train[:, 0]**2 + X_train[:, 1]**2 > 1.5).astype(int)
            
            # Add noise
            noise_idx = np.random.choice(200, 20, replace=False)
            y_train[noise_idx] = 1 - y_train[noise_idx]
            
            # Train and predict
            model = base_model.__class__(**base_model.get_params())
            model.fit(X_train, y_train)
            pred = model.predict(X_test)
            predictions.append(pred)
        
        # Calculate variance
        predictions = np.array(predictions)
        variance = np.var(predictions, axis=0).mean()
        
        print(f"\n{name}:")
        print(f"  Average prediction variance: {variance:.4f}")
        print(f"  Prediction stability: {1 - variance:.4f}")

Best Practices

🎯 Bagging Best Practices

  • Base Estimator: Use high-variance models (deep trees) as base estimators
  • Number of Estimators: More is generally better, diminishing returns after 50-100
  • Sample Size: Default 100% works well, try 70-80% for large datasets
  • Feature Sampling: Random feature subsets can improve diversity
  • OOB Score: Use for model selection without separate validation set
  • Parallel Training: Set n_jobs=-1 for parallel processing
  • Random Forest: Prefer over basic bagging for most tasks
  • Avoid with: Low-variance models like linear regression

🎓 Key Takeaways

  • Bagging trains many base learners on bootstrap samples (sampling with replacement) and aggregates them by voting or averaging.
  • Its main benefit is variance reduction, so it shines with high-variance, low-bias models like deep decision trees.
  • The out-of-bag (OOB) score gives a built-in performance estimate from the samples each model never saw.
  • Random Forest is bagging plus random feature selection at each split, which further decorrelates the trees.

❓ Common Questions at This Stage

Does bagging help every kind of model?

Not equally. Bagging mainly reduces variance, so it helps unstable, high-variance models (like fully grown trees) the most. Applying it to a stable, high-bias model such as linear regression gives little benefit.

How is bagging different from boosting?

Bagging trains its models independently and in parallel on random bootstrap samples to reduce variance. Boosting trains models sequentially, each focusing on the previous model's mistakes, and mainly reduces bias.

Is Random Forest just bagging with trees?

Almost — it is bagging of decision trees plus one extra idea: at each split only a random subset of features is considered. That extra randomness decorrelates the trees and usually improves the ensemble further.
