🤖 Machine Learning Foundations: Course Syllabus

An instructor-led course in 11 three-hour sessions. Learn supervised machine learning the way it is done at work: frame the question, prepare the data without leaking, train and compare models fairly, tune them, and report results you can defend, all practiced on one fictional company's data.

📚 Course Description

Machine learning is mostly not about clever algorithms. It is about asking a precise question, preparing data honestly, comparing models fairly against a baseline, and knowing when a score is too good to be true. This course teaches those habits first and then the main families of models, with scikit-learn, in the order you would use them on a real project.

Every session uses the same company: Pinecrest Outfitters, a fictional outdoor-gear retailer with an online shop and four stores. Its seven data files were built for machine learning: customers who might churn, weekly product demand, card payments with rare fraud, product reviews, purchase histories and daily store sales, each with real patterns to find and a few traps (a leaking column, a rare class, a drifting rate) to catch.

🎯 By the end you will be able to

  • Frame a business request as a classification or regression problem with a clear target
  • Split data honestly (stratified, grouped, by time), catch target leakage, and cross-validate
  • Choose the right metric, and set a decision threshold from the costs of mistakes
  • Impute, scale, encode and engineer features inside leak-proof pipelines
  • Handle rare classes with class weights, resampling and thresholds
  • Train and read linear models, k-nearest neighbors, naive Bayes, SVMs, trees, forests and gradient boosting
  • Compare models fairly, tune them with cross-validation and Optuna, and report the result honestly

Continue with Advanced Machine Learning (13 sessions): explaining models, clustering and anomaly detection, dimensionality reduction, deep learning with PyTorch, text and recommendations, MLOps and a capstone.

✅ Prerequisites

  • Python and pandas at the level of Python Data Science (free at Ray's House of Fun): writing functions, filtering and grouping DataFrames, handling missing values, and making a basic Matplotlib chart.
  • No machine-learning experience is needed. Comfortable reading a formula with a sum in it; no calculus.
  • A Windows, macOS or Linux laptop on which you can install software, with about 3 GB free. Setup is done at home before Session 1 (it follows Lesson 0.1).

💡 Format

11 sessions × 3 hours = 33 class hours, two lessons per session (the studio session 11 focuses on one). Every lesson on the course site is written for a solo learner and takes about 90 to 120 minutes, so two lessons do not fit whole in one room session. The room protects what is hardest alone: the mental model, a live-coding demo you type along with, a guided lab with help on hand, and starting each lesson project. At home you finish the projects and do each lesson's exercises, quiz and journal entry on the free course site: about two to three hours between sessions.

Each session runs 0:00 to 3:00: a warm-up on last session, the first lesson, a 10-minute break, the second lesson, and a wrap-up with an exit ticket and the next bring list.

Twice weekly: about 6 weeks. Two homework sets a week, so plan on four to six hours outside class.
Weekly: 11 weeks, with a full week for each homework set.
Intensive days: two sessions a day; homework becomes evening practice and the final project is finished afterward.

🏁 Checkpoint and Project

  • Self-checks and exit tickets in every session are practice, not grades: they tell you and your instructor what to revisit.
  • Checkpoint 1 (Session 6, 30 minutes): an individual, open-notebook task on the workflow and data preparation (Modules 1 and 2), scored with a short rubric.
  • Final project. In Session 10 you choose one Pinecrest problem (who will churn, how many units each store will sell, or which payments are fraud) and write a one-paragraph plan. Session 11 is a studio with milestone check-ins, then a showcase. You hand in a notebook that reruns from top to bottom and a short report: the framing, an honest split and baseline, a tuned model compared fairly with simpler ones, the metric that matters to the business, and what you would and would not claim. A well-supported modest result scores as well as a dramatic one.

🧰 Required Software and Data

  • Python 3.12 or newer: with a virtual environment for the course
  • The course packages: one command: python -m pip install -r requirements.txt (scikit-learn 1.9, pandas 3.0, NumPy, Matplotlib, XGBoost, LightGBM, imbalanced-learn, Optuna, and the rest of the course's list, including PyTorch for later modules)
  • JupyterLab or VS Code: JupyterLab installs with the packages; VS Code needs its Python and Jupyter extensions
  • The course data: pinecrest-ml-data.zip (1.4 MB) from the course home page
  • No GPU, accounts or paid tools: everything runs on an ordinary laptop processor

Everything installs once, at home, before Session 1, following Lesson 0.1. Your instructor sends a setup guide and an environment check a week ahead.
