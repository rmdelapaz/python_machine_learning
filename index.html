📚 About This Course

Machine learning is not a list of algorithms. It is a way of working: frame a question a model can answer, prepare the data without leaking the answer into it, compare honest candidates against a simple baseline, explain what the winner learned, and put it to work. This course teaches the Python tools for each of those steps, in the order you would use them on a real project.

  1. Frame
  2. Prepare
  3. Train
  4. Evaluate
  5. Explain
  6. Deploy

🎯 What You Will Be Able to Do

  • Train, evaluate and compare models with scikit-learn's estimator API and pipelines
  • Choose the right split, cross-validation scheme and metric, and spot data leakage
  • Prepare features: impute, scale, encode, create and select them
  • Use linear models, nearest neighbors, naive Bayes, SVMs, trees, random forests and gradient boosting
  • Tune hyperparameters and explain models with permutation importance, SHAP and LIME
  • Find customer segments, anomalies and structure with clustering and dimensionality reduction
  • Build and train neural networks in PyTorch, including CNNs, LSTMs and transfer learning
  • Track experiments, save models safely and serve one behind an API

✅ Prerequisites

This course continues where Python Data Science ends. You should be comfortable with Python itself (functions, loops, lists and dictionaries, files, basic classes) and with the data tools: NumPy arrays, pandas DataFrames (loading, filtering, grouping, merging), Matplotlib charts, and basic statistics such as means, distributions and correlation.

If any of that is new, take the Intro and Intermediate Python courses at Ray's House of Fun and then Python Data Science first. No previous machine learning is needed, and the math is explained in words and pictures as it comes up.

You will need: a Windows, macOS or Linux computer on which you can install software, Python 3.12 or newer, about 5 GB of free disk space and 8 GB of memory. No graphics card is needed: every lesson, deep learning included, runs on an ordinary CPU. Lesson 0.1 walks you through the setup.

💡 How the Course Works

  1. Go in order. Lessons assume the ones before them. Module 1 sets habits (baselines, honest splits, pipelines) that every later lesson relies on.
  2. Type along. Every code block shows its real output underneath. Run each one yourself and compare. Where results depend on your computer (training times, some neural-network numbers), the lesson says so.
  3. Build the project. Each lesson has one guided project on the course data, with a complete solution and a checklist.
  4. Do the exercises, then the quiz. Three to five exercises with hidden solutions, and five quick questions that give you a hint when you miss.
  5. Write in your journal. Five minutes at the end of each lesson. It is the cheapest way to make learning stick.

Each lesson shows an honest time estimate that includes the typing, the project and the quiz.

Taking or teaching it in a classroom? The course runs as two instructor-led programs: Machine Learning Foundations (Modules 0 to 6, 11 three-hour sessions) and Advanced Machine Learning (Modules 7 to 13, 13 three-hour sessions).

🏔️ The Data: Pinecrest Outfitters

The lessons use data from Pinecrest Outfitters, an outdoor-gear retailer with an online shop and stores in Boise, Bend, Flagstaff and Asheville (you may know it from the Data Science course). The company is fictional, and so is every customer, product and number. Each table was written for this course to behave like the real thing, with the patterns, noise and traps of real data.

  • Customer churn: 6,000 customers, who stayed and who left (classification, clustering)
  • Weekly demand: units sold per product, store and week, with prices and promotions (regression)
  • Card payments: 50,000 transactions, under 1% of them fraud (imbalanced data, anomalies)
  • Product reviews: 4,000 short reviews with star ratings (text classification)
  • Purchases and ratings: 3,000 customers and 200 products (recommendations)
  • Daily store sales: three years, four stores (sequence models)
⬇️ Download the data (1.4 MB zip) requirements.txt

Unzip it inside your project folder so that you have a data folder next to your notebooks. The zip includes a README describing every file and column, and the script that generated the data. The image lessons use two public datasets, Fashion-MNIST and EuroSAT, which PyTorch downloads for you when the lesson asks.

📖 Course Modules

0 🧰 Start Here 1 lesson · 1 h 30 min

Set up the ML environment, meet the end-to-end workflow, and get to know the Pinecrest machine-learning data.

  • 0.1 Your ML Toolkit 90 min Build the environment, learn the workflow from question to model, and load the Pinecrest ML data.

1 🔁 The ML Workflow 4 lessons · 6 h 30 min

The habits every project needs: the estimator API, honest splits, cross-validation and the right metric.

  • 1.1 The scikit-learn Estimator API 90 min fit, predict, score and transform: train a baseline and a first churn model end to end.
  • 1.2 Splits, Baselines and Leakage 100 min Hold out test data properly, stratify, split by time, and catch target leakage.
  • 1.3 Cross-Validation 95 min K-fold, stratified, grouped and time-series cross-validation, and what the spread tells you.
  • 1.4 Metrics for Classification and Regression 105 min Accuracy, precision, recall, ROC and PR curves, MAE, RMSE and R², and when each misleads.

2 🧹 Preparing Data 5 lessons · 8 h 15 min

Turn raw tables into model-ready features without leaking information from the test set.

  • 2.1 Impute, Scale and Encode 95 min Missing values, scaling and categorical encoding with ColumnTransformer.
  • 2.2 Pipelines 100 min Chain preprocessing and models into one leakage-proof object you can tune and save.
  • 2.3 Creating Features 100 min Dates, ratios, aggregates and interactions that give a model something to learn.
  • 2.4 Feature Selection 100 min Filter, wrapper and embedded methods for dropping redundant and useless features.
  • 2.5 Imbalanced Classes 100 min Class weights, resampling and threshold choice when the event you care about is rare.

3 📈 Linear Models 2 lessons · 3 h 20 min

The workhorse models: fast, interpretable, and the baseline every other model must beat.

  • 3.1 Linear and Logistic Regression 100 min Fit, read and check linear and logistic models on Pinecrest demand and churn.
  • 3.2 Regularization and the Bias-Variance Trade-off 100 min Ridge, Lasso, Elastic Net and polynomial features; underfitting versus overfitting.

4 🧭 Classic Classifiers 3 lessons · 4 h 50 min

Three classic ideas about classification: distance, probability and margins.

  • 4.1 k-Nearest Neighbors 95 min Classify by similarity, and see why scaling and the choice of k matter.
  • 4.2 Naive Bayes 95 min A fast probabilistic classifier, and why it shines on text.
  • 4.3 Support Vector Machines 100 min Maximum-margin classifiers and the kernel trick.

5 🌲 Trees and Ensembles 4 lessons · 6 h 35 min

Decision trees and the ensembles built from them: often the strongest models for tabular data.

  • 5.1 Decision Trees 100 min Splits, depth and impurity: a model you can draw, and how it overfits.
  • 5.2 Bagging and Random Forests 100 min Many decorrelated trees that vote, with out-of-bag error for free.
  • 5.3 Gradient Boosting 100 min HistGradientBoosting, XGBoost and LightGBM: trees that fix each other's mistakes.
  • 5.4 Voting and Stacking 95 min Combine different models into one that is better than each.

6 🎛️ Model Selection and Tuning 2 lessons · 3 h 25 min

Choose between models fairly and tune them without fooling yourself.

  • 6.1 Model Selection and Learning Curves 100 min Compare models on equal terms; read learning and validation curves.
  • 6.2 Hyperparameter Tuning 105 min Grid search, random search, successive halving and Optuna, with nested cross-validation.

7 🔍 Explaining Models 3 lessons · 4 h 50 min

Find out what a model learned, explain single predictions, and check it for unfairness.

  • 7.1 Interpreting Models 95 min Coefficients, permutation importance, partial dependence and ICE plots.
  • 7.2 SHAP Values 95 min Explain any prediction as a sum of feature contributions.
  • 7.3 LIME and Fairness Checks 100 min Local surrogate explanations, and comparing error rates across groups.

8 🧩 Clustering and Anomalies 6 lessons · 9 h 55 min

Find structure without labels: customer segments, density, mixtures and outliers.

  • 8.1 K-Means Clustering 95 min How K-Means works, why scaling matters, and how to read the clusters.
  • 8.2 Choosing k and Customer Segments 100 min Elbow, silhouette and stability; turn clusters into named customer segments.
  • 8.3 Hierarchical Clustering 95 min Linkage methods and dendrograms.
  • 8.4 Density-Based Clustering 100 min DBSCAN, OPTICS and HDBSCAN: clusters of any shape, and noise.
  • 8.5 Gaussian Mixture Models 95 min Soft clustering with probabilities, and choosing components with BIC.
  • 8.6 Anomaly Detection 110 min Isolation Forest, Local Outlier Factor and a payment-fraud project.

9 🗜️ Dimensionality Reduction 3 lessons · 4 h 50 min

Compress many features into a few, for modeling and for pictures.

  • 9.1 Principal Component Analysis 100 min Variance, components and how many to keep.
  • 9.2 Linear Discriminant Analysis 90 min Supervised projection that separates classes.
  • 9.3 t-SNE and UMAP 100 min Nonlinear embeddings for visualization, and how not to over-read them.

10 🧠 Deep Learning with PyTorch 5 lessons · 9 h 10 min

Neural networks from first principles to pretrained models, all running on an ordinary CPU.

  • 10.1 Neural Networks from Scratch 105 min Neurons, layers, loss and gradient descent in NumPy, then with autograd.
  • 10.2 PyTorch Fundamentals 110 min Tensors, modules, datasets and the training loop.
  • 10.3 Convolutional Neural Networks 110 min Convolutions and pooling; an image classifier for Fashion-MNIST.
  • 10.4 Sequence Models 115 min RNNs and LSTMs for daily store sales, and a first look at attention.
  • 10.5 Transfer Learning 110 min Reuse a pretrained torchvision model on a small image dataset.

11 🛍️ Applied ML 2 lessons · 3 h 25 min

Two applications every retailer uses: understanding text and recommending products.

  • 11.1 Text Classification 95 min Tokens, TF-IDF and a sentiment model for Pinecrest product reviews.
  • 11.2 Recommendation Systems 110 min Popularity, item similarity and matrix factorization, evaluated with hit rate.

12 🚀 MLOps 2 lessons · 3 h 30 min

Make results reproducible, track experiments, and put a model behind an API.

  • 12.1 Reproducibility and Experiment Tracking 105 min Seeds, environments, saving models safely and tracking runs with MLflow.
  • 12.2 Serving and Monitoring Models 105 min Serve a model with FastAPI and watch for data drift.

13 🏔️ Capstone 2 lessons · 10 h

Put the whole workflow together: one guided case study, then a project of your own.

  • 13.1 Case Study: Predicting Churn 120 min Question, data, features, models, tuning, explanation and a recommendation, end to end.
  • 13.2 Capstone Project 480 min Your own Pinecrest ML project, from question to a written model report, with a rubric.
