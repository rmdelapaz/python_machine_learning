Warm-up

0:00

Retrieval from Lessons 11.2 and 12.1

10 min
Five questions (with answers)
  1. Lesson 11.2 hid each customer's LATEST purchase for testing, not a random one. Why? Answer: It mimics the real job (predict the next purchase from earlier ones) and keeps future purchases out of the training matrix: the same rule as splitting by time in Lesson 1.2.
  2. Best sellers scored a hit rate at 10 of 0.209 and item-kNN 0.308. Say what 0.308 means in one sentence. Answer: For about 31% of customers, the product they really bought next was in their personal top-10 list (already-owned products excluded): about 50% more often than the best-seller list.
  3. Why did SVD with 40 factors recommend worse than with 5? Answer: With many factors it memorizes each customer's past basket instead of broad tastes, so it generalizes worse (0.19 against 0.311 at k = 5).
  4. A colleague emails you churn_model.joblib. What is the risk of loading it, and what did Lesson 12.1 use instead? Answer: A joblib file is a pickle: loading it can run arbitrary code. Lesson 12.1 saved with skops, which loads only reviewed types passed to trusted=.
  5. Your model card stores a SHA-256 of customers_churn.csv. Today the hash differs. What do you know, and what don't you? Answer: The file is not byte-for-byte the one the model was trained on; the hash cannot say what changed (one row, the order, a column).

    """serve.py: the Pinecrest churn-scoring API."""
import json

import pandas as pd
import skops.io as sio
from fastapi import FastAPI

from schemas import Customer, Score

with open("churn_serving.json") as f:
    SERVING = json.load(f)
with open(SERVING["model_card"]) as f:
    CARD = json.load(f)
MODEL = sio.load(CARD["model_file"], trusted=CARD["skops_trusted_types"])   # only the reviewed types
FEATURES = SERVING["features"]
DTYPES = SERVING["dtypes"]
THRESHOLD = SERVING["threshold"]
VERSION = SERVING["version"]

app = FastAPI(title="Pinecrest churn scoring", version=VERSION)


def to_frame(customers: list[Customer]) -> pd.DataFrame:
    """Validated customers to a DataFrame with the training columns, order and dtypes."""
    rows = [c.model_dump() for c in customers]
    return pd.DataFrame(rows, columns=FEATURES).astype(DTYPES)


def to_score(p: float) -> Score:
    return Score(churn_probability=round(float(p), 4), offer=bool(p >= THRESHOLD), model_version=VERSION)


@app.get("/health")
def health() -> dict:
    return {"status": "ok", "model_version": VERSION}


@app.post("/predict")
def predict(customer: Customer) -> Score:
    return to_score(MODEL.predict_proba(to_frame([customer]))[0, 1])


@app.post("/predict_batch")
def predict_batch(customers: list[Customer]) -> list[Score]:
    return [to_score(p) for p in MODEL.predict_proba(to_frame(customers))[:, 1]]

  12. PSI points at what moved (3m). Write the PSI formula and the 0.1 / 0.25 conventions on the board. "Chosen before you look." 
    def psi(reference, current, bins=10):
    """Population Stability Index of one numeric column; missing values get their own bin."""
    edges = np.unique(np.quantile(reference.dropna(), np.linspace(0, 1, bins + 1)))
    edges[0], edges[-1] = -np.inf, np.inf
    def shares(values):
        counts = np.append(np.histogram(values.dropna(), bins=edges)[0], values.isna().sum())
        return np.clip(counts / len(values), 1e-4, None)      # avoid log(0) for empty bins
    ref, cur = shares(reference), shares(current)
    return float(np.sum((cur - ref) * np.log(cur / ref)))
drift = pd.DataFrame({
    "psi_stable": {col: psi(X_train[col], stable[col]) for col in NUMERIC},
    "psi_shifted": {col: psi(X_train[col], shifted[col]) for col in NUMERIC},
})
drift["status"] = pd.cut(drift["psi_shifted"], [-np.inf, 0.1, 0.25, np.inf], labels=["stable", "watch", "SHIFT"])

  4. The leak check (4m). "Nobody tells you which column is the trap. Add the suspicious one and see." 
    from sklearn.compose import ColumnTransformer
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold, cross_val_score
def make_prep(numeric, categorical):
    return ColumnTransformer([
        ("num", make_pipeline(SimpleImputer(strategy="median"), StandardScaler()), numeric),
        ("cat", make_pipeline(SimpleImputer(strategy="most_frequent"),
                              OneHotEncoder(handle_unknown="ignore", sparse_output=False)), categorical),
    ])

honest = make_pipeline(make_prep(NUMERIC, CATEGORICAL), LogisticRegression(max_iter=1000))
