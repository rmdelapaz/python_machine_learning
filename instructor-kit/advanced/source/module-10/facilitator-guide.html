Session 10: Recommendations and Reproducibility

How to teach Session 10 of Advanced Machine Learning: turn 32,000 purchases into a personal "Picked for You" list and prove with an honest leave-last-out test that it beats the best sellers (0.308 vs 0.209), then make results reproducible and models safe to share: seeds, fingerprints, versions, skops instead of pickles, and an MLflow store that answers "which settings gave this number?".

How to Use This Guide

  • Every code block below was run to produce its output (scikit-learn 1.9.1, SciPy, MLflow 3.17.1, skops 0.16.0, 4 CPU threads). MLflow run IDs and timings differ on every machine; nothing else should.
  • Keep applications_recommendation_systems.html and mlops_intro.html open for the figures (long tail, the leave-last-out diagram, hit rate against k, the lab-notebook diagram). Labs are in labs/module-10/.

Two habits this session is really about

Both lessons are about evaluation discipline more than algorithms. In 11.2, hide something real (the last purchase), ask the model to find it, compare with a baseline that knows nothing about the customer, and choose settings on a validation item. In 12.1, make that number provable later: seed, fingerprint, versions, settings, and a model file that cannot run code when someone opens it. Keep returning to "compared with what?" and "could you prove it in six months?"

Warm-up: Transfer Learning and Text

10 min
How to run it
  • Five questions on the slide, two minutes alone, answers by show of hands. Homework check: who has landcover_resnet18.pt (12.1 will talk about saving files like it) and review_follow_up.csv.
Questions and answers
W1
What does this print?
from torch import nn
from torchvision import models
m = models.resnet18(weights=None)
for p in m.parameters():
    p.requires_grad = False
m.fc = nn.Linear(512, 5)
print(sum(p.numel() for p in m.parameters() if p.requires_grad))
2565
Why: Frozen first, then a new 5-class head: 512 × 5 + 5 = 2,565. New layers are trainable by default.
W2
What does this print?
from sklearn.feature_extraction.text import CountVectorizer
print(CountVectorizer().build_analyzer()("Not bad, NOT bad at all!"))
['not', 'bad', 'not', 'bad', 'at', 'all']
Why: Lowercased, punctuation dropped, every occurrence kept in order by the analyzer. Counted as a bag: not 2, bad 2, at 1, all 1. A unigram model cannot tell Not bad from bad.
W3
Why must the backbone be in eval() mode while you extract features?
Batch normalization must use its stored ImageNet statistics; in training mode a tile's features depend on its batch and the stored statistics drift.
Why: no_grad does not do this: it only switches off gradient tracking.
W4
Someone fits a TfidfVectorizer on all reviews, then splits. What is wrong, and how do you fix it?
Test reviews shape the vocabulary and the IDF values: a leak. Split first, fit inside a pipeline.
Why: Today's recommender has the same rule in a new costume: the matrix is built from training purchases only.
W5
Frozen features: 0.885 with 500 labels, 0.902 with 2,000. What is the better next step than labeling more?
Fine-tune the top block (layer4) with a small learning rate: validation 0.876 → 0.924 in the project.
Why: Measuring what more data buys, before paying for it, is the habit.

Mental model to say

"A long-serving clerk at the Bend store has watched thousands of customers. When a regular buys a climbing harness she does not reach for the best-selling socks: 'People who buy that harness usually come back for a chalk bag.' No rule book; she noticed which products end up with the same customers. That is collaborative filtering. A new clerk can only point at the best sellers (popularity) or read the labels (content-based). Today we build all three and measure which helps customers most."

Then the shape of the problem: no target column, a big mostly empty grid of customers × products, and the job is to RANK the empty cells. "The tools you know: cosine similarity from kNN, a cousin of PCA, and holding out data you never train on."

  5. A sparse matrix from training rows (2m). "Rows are customers, columns products, a 1 where they bought." 
    from scipy.sparse import csr_matrix
customer_ids = np.sort(interactions["customer_id"].unique())
product_ids = products["product_id"].to_numpy()
row_of = pd.Series(np.arange(len(customer_ids)), index=customer_ids)
col_of = pd.Series(np.arange(len(product_ids)), index=product_ids)
R = csr_matrix(
    (np.ones(len(train)), (row_of[train["customer_id"]].to_numpy(), col_of[train["product_id"]].to_numpy())),
    shape=(len(customer_ids), len(product_ids)),
)

  6. Two helpers for every recommender (3m). "Any recommender is a score matrix. Mask what they own, sort descending, take ten." Narrate each line of top_k. 
    owned = R.toarray() > 0
test_col = col_of[test.set_index("customer_id").loc[customer_ids, "product_id"]].to_numpy()

def top_k(scores, k=10):
    scores = np.array(scores, dtype=float)      # a copy, so the caller's matrix is untouched
    scores[owned] = -np.inf                     # never recommend what they already have
    return np.argsort(-scores, axis=1)[:, :k]   # column numbers of the k highest scores

def hit_rate(scores, k=10):
    return (top_k(scores, k) == test_col[:, None]).any(axis=1).mean()

print(owned.shape, test_col[:5])
    (3000, 200) [196  46 197  98 107]

Three mistakes to expect, and how to coach each
  • Similarity on the wrong axis. ValueError: matmul: dimension mismatch with signature (n,k=200),(k=3000,m)->(n,m). Coach: "Print the shape of your similarity matrix. Products × products?" Pass R.T.
  • Sorting ascending, or forgetting the mask. Silent: HR@10: 0.001 (ascending) and owned slots: 14%, HR@10 without the mask: 0.270. Coach: "Compare with random (0.047). A model that loses to random is a bug."
  • Tuning on the test item. Silent and tempting after the k chart. Coach: "Which purchase did you use to choose k?" The project's validation item is the answer.

Checks for understanding
  • What does one row of R @ item_sim hold? Answer: each product's summed similarity to everything that customer owns.
  • Why is a random list's hit rate about 0.05? Answer: 10 picks from about 190 unowned products.
  • Why can item-kNN never recommend a brand-new product? Answer: its column is all zeros, so its similarity to everything is 0.
  • Name one cost of the best-seller list besides hit rate. Answer: coverage (31 products); it buries the long tail and new products.

Mental model to say

"A good chemist writes every experiment in a bound lab notebook: which batch of each chemical, which instrument, the temperature, the result, even the failures. Anyone can repeat it, and nobody argues about what was done." Write the five ingredients: code (Git), data (the exact bytes), environment (versions), randomness (seeds), settings (hyperparameters, features, split). "Record all five plus the results and you have a lab notebook for models. MLflow is a lab notebook that fills itself in."

Then the uncomfortable half: "A saved model file is not data. A pickle is a small program, and opening it runs it. How you load a model decides whether a stranger's file can run commands on your machine."

from sklearn.preprocessing import OneHotEncoder, StandardScaler

customers = pd.read_csv("data/customers_churn.csv")
numeric = ["tenure_months", "orders_12m", "spend_12m", "avg_order_value", "days_since_last_order", "returns_12m",
           "return_rate", "support_tickets_12m", "discount_share", "app_user", "email_opens_90d"]

X, y = customers[numeric + categorical], customers["churned"]

def build_pipeline(model):
    prep = ColumnTransformer([
        ("num", make_pipeline(SimpleImputer(strategy="median"), StandardScaler()), numeric),
        ("cat", make_pipeline(SimpleImputer(strategy="most_frequent"), OneHotEncoder(handle_unknown="ignore")), categorical),
    ])
    return Pipeline([("prep", prep), ("model", model)])

  2. Randomness: seeds (3m). "Fit the same forest twice without a seed, then with one." 
    from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import roc_auc_score

def forest_probabilities(seed):
    forest = build_pipeline(RandomForestClassifier(n_estimators=50, min_samples_leaf=5, random_state=seed))
    return forest.fit(X_train, y_train).predict_proba(X_test)[:, 1]

print("no seed:  two fits identical?", np.array_equal(forest_probabilities(None), forest_probabilities(None)))
print("seed 42:  two fits identical?", np.array_equal(forest_probabilities(42), forest_probabilities(42)))
for seed in [42, 7]:
    print(f"seed {seed:2d}: test AUC {roc_auc_score(y_test, forest_probabilities(seed)):.4f}")

  3. Data: a fingerprint, not a file name (2m). "Change one character and all 64 change." 
    import hashlib

def file_sha256(path):
    digest = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(1_000_000), b""):   # 1 MB at a time: works for huge files
            digest.update(chunk)
    return digest.hexdigest()

data_hash = file_sha256("data/customers_churn.csv")

Three mistakes to expect, and how to coach each
  • Saving the classifier instead of the pipeline. ValueError: could not convert string to float: 'Asheville' (raw columns reach a model that expects preprocessed numbers). Coach: "What does your file contain: type(obj)?" Save the whole Pipeline.
  • Trusting whatever the file asks for. trusted=sio.get_untrusted_types(file=path) silences skops and defeats it. Coach: "Read me the list. Which of these did you expect for this model?" (Lab 12.1 B: the list depends on the model.)
  • The old mlruns store and parameters changed inside a run. Loud, with good messages. Coach: one run per setting, sqlite:///mlflow.db, and read the message to the end: it names the fix.
