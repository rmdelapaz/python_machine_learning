9.2

Linear Discriminant Analysis

60 min
Objectives (from the lesson page)
  • Explain how LDA differs from PCA: it uses the labels to find directions that separate classes
  • Use LDA to reduce dimensions for a plot or as a step before another model
  • Use LDA as a classifier and compare it with logistic regression
  • Know the limit on components (classes minus one) and when shrinkage helps
  • Keep LDA inside the pipeline so cross-validation stays honest
Timing in the room
10mFrame: the team photo; Fisher's criterion in words; at most classes minus one axes
20mLive demo: PCA vs LDA, the churn axis, LDA as a classifier, more classes, shrinkage, mistakes, the noise leak
20mGuided lab: payment_category_lda_starter.py, then noise_leak_starter.py in pairs
10mStart the lesson project: The Loyalty-Tier Map, Steps 1 and 2
Mental model to say

"Two hiking clubs pose on a field and you photograph them from the side, so the picture flattens everyone onto one line. PCA picks the angle that makes the crowd look widest, even if the clubs end up mixed. LDA walks around the field until the two clubs appear as two tight, separate groups: each bunched up, the two far apart."

Then the consequence to memorize: the class means of C classes span at most C - 1 directions, so two classes give one axis and three tiers give two, however many features.

Live demo (you type, they follow)
  1. Two methods, one picture (3m). "Two long, thin, parallel classes. Predict: where does PCA point, where does LDA point?" Show the lesson's three-panel figure. 
    import numpy as np
import pandas as pd
from sklearn.decomposition import PCA
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
rng = np.random.default_rng(42)
n = 200
along = rng.normal(0, 3, 2 * n)
across = rng.normal(0, 0.6, 2 * n) + np.repeat([-1.0, 1.0], n)
angle = np.deg2rad(30)
rotation = np.array([[np.cos(angle), -np.sin(angle)], [np.sin(angle), np.cos(angle)]])
toy_X = np.column_stack([along, across]) @ rotation.T
toy_y = np.repeat([0, 1], n)
toy_pca = PCA(n_components=1).fit(toy_X)
toy_lda = LinearDiscriminantAnalysis(n_components=1).fit(toy_X, toy_y)
lda_dir = toy_lda.scalings_[:, 0] / np.linalg.norm(toy_lda.scalings_[:, 0])
print("PCA direction:", toy_pca.components_[0].round(3))
print("LDA direction:", lda_dir.round(3))
    PCA direction: [0.866 0.5  ]
LDA direction: [-0.489  0.872]
    Almost at right angles: PCA follows the long axis (the spread), LDA points across the classes.
  2. What each one keeps (2m). "Distance between the class means, in within-class standard deviations." 
    def separation(z, labels):
    """Distance between the two class means, in units of the average within-class std."""
    a, b = z[labels == 0], z[labels == 1]
    return abs(a.mean() - b.mean()) / np.sqrt((a.var() + b.var()) / 2)
print(f"separation on PC1: {separation(toy_pca.transform(toy_X)[:, 0], toy_y):.2f}")
print(f"separation on LD1: {separation(toy_lda.transform(toy_X)[:, 0], toy_y):.2f}")
    separation on PC1: 0.05
separation on LD1: 3.32
  3. One axis for churn (4m). "Two classes, at most one axis. Its weights read like a churn story." 
    from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
customers = pd.read_csv("data/customers_churn.csv")
features = ["tenure_months", "orders_12m", "spend_12m", "avg_order_value", "days_since_last_order",
            "returns_12m", "return_rate", "support_tickets_12m", "discount_share", "app_user"]
X = customers[features]
y = customers["churned"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, stratify=y, random_state=42)
scaler = StandardScaler().set_output(transform="pandas")
X_train_s = scaler.fit_transform(X_train)
X_test_s = scaler.transform(X_test)
lda = LinearDiscriminantAnalysis()
lda.fit(X_train_s, y_train)
churn_axis = lda.transform(X_test_s)
print("transformed shape:", churn_axis.shape)
print(pd.Series(lda.scalings_[:, 0], index=features).round(2).sort_values().iloc[[0, 1, -3, -2, -1]])
    transformed shape: (1500, 1)
app_user                -0.21
tenure_months           -0.09
support_tickets_12m      0.30
discount_share           0.50
days_since_last_order    0.92
dtype: float64
    Days since the last order dominates, then discounts and tickets; app users on the other side. Lesson 9.1's PCA buried recency; LDA puts it first because the labels told it to.
  4. LDA as a classifier (3m). "The same object predicts: Gaussian classes with one shared covariance, so a straight boundary." 
    from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.discriminant_analysis import QuadraticDiscriminantAnalysis
from sklearn.metrics import accuracy_score, roc_auc_score
models = {"baseline": DummyClassifier(strategy="prior"), "LDA": LinearDiscriminantAnalysis(),
          "logistic regression": LogisticRegression(), "QDA": QuadraticDiscriminantAnalysis()}
for name, model in models.items():
    model.fit(X_train_s, y_train)
    proba = model.predict_proba(X_test_s)[:, 1]
    acc = accuracy_score(y_test, model.predict(X_test_s))
    print(f"{name:20s} accuracy {acc:.3f}   ROC AUC {roc_auc_score(y_test, proba):.3f}")
    baseline             accuracy 0.835   ROC AUC 0.500
LDA                  accuracy 0.853   ROC AUC 0.824
logistic regression  accuracy 0.848   ROC AUC 0.823
QDA                  accuracy 0.813   ROC AUC 0.803
    Neck and neck with logistic regression. QDA (one covariance per class) is worse: flexibility is not free.
  5. More classes, more axes (2m). "Four classes in ten dimensions." 
    from sklearn.datasets import make_blobs
blobs_X, blobs_y = make_blobs(n_samples=400, centers=4, n_features=10, cluster_std=3.0, random_state=42)
blob_lda = LinearDiscriminantAnalysis().fit(blobs_X, blobs_y)
print("transform shape:", blob_lda.transform(blobs_X).shape)
print("separation carried by each axis:", blob_lda.explained_variance_ratio_.round(3))
    transform shape: (400, 3)
separation carried by each axis: [0.781 0.136 0.083]
    The ratio is the share of class SEPARATION, not of total variance.
  6. Many features, few rows: shrinkage (2m). "100 rows, 200 features." 
    from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_score, StratifiedKFold
wide_X, wide_y = make_classification(n_samples=100, n_features=200, n_informative=10, n_redundant=0, random_state=42)
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for name, model in [("plain LDA (svd)", LinearDiscriminantAnalysis()),
                    ("LDA with shrinkage", LinearDiscriminantAnalysis(solver="lsqr", shrinkage="auto"))]:
    print(f"{name:20s} CV accuracy {cross_val_score(model, wide_X, wide_y, cv=cv).mean():.3f}")
    plain LDA (svd)      CV accuracy 0.540
LDA with shrinkage   CV accuracy 0.680
  7. Two loud mistakes (1m). "Too many axes; shrinkage with the default solver." 
    LinearDiscriminantAnalysis(n_components=2).fit(X_train_s, y_train)
LinearDiscriminantAnalysis(shrinkage="auto").fit(X_train_s, y_train)
    ValueError: n_components cannot be larger than min(n_features, n_classes - 1).
NotImplementedError: shrinkage not supported with 'svd' solver.
  8. The quiet mistake: LDA before cross-validation (3m). "Pure noise, random labels. No honest model beats one in three." 
    from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
noise_X = rng.normal(size=(100, 500))
noise_y = rng.integers(0, 3, size=100)
reduced = LinearDiscriminantAnalysis(n_components=2).fit_transform(noise_X, noise_y)
leaky = cross_val_score(KNeighborsClassifier(n_neighbors=5), reduced, noise_y, cv=cv).mean()
honest_pipe = make_pipeline(LinearDiscriminantAnalysis(n_components=2), KNeighborsClassifier(n_neighbors=5))
honest = cross_val_score(honest_pipe, noise_X, noise_y, cv=cv).mean()
print(f"LDA fitted on all rows, then CV: {leaky:.2f}")
print(f"LDA inside the pipeline:         {honest:.2f}")
    LDA fitted on all rows, then CV: 0.62
LDA inside the pipeline:         0.34
    Write both numbers on the board. Every supervised step (LDA, target encoding, selection that looks at y) belongs inside the pipeline. The lab repeats this on real customers.
Three mistakes to expect, and how to coach each
  • Asking for too many axes. n_components=2 for churn. Coach: "How many classes? Minus one."
  • Reading LDA's explained_variance_ratio_ as PCA's. Coach: "Share of what? Of the separation between classes."
  • Reducing before cross-validating. Coach with the board: 0.62 vs 0.34, and in the lab 0.998 vs 0.481.

Mental model to say

"You seat 1,000 wedding guests in one hall; the only rule is: sit near the people you know best. The tables of friends mean something.   4. What a map distorts (3m). "Three groups whose truth we know: tight, wide, far away." 
    from sklearn.datasets import make_blobs
blob_X, blob_y = make_blobs(n_samples=[100, 100, 100], centers=[[0, 0], [6, 0], [30, 0]],
                            cluster_std=[0.3, 2.0, 1.0], random_state=42)
blob_emb = TSNE(perplexity=30, random_state=42).fit_transform(blob_X)
def spread(Z, g):
    return Z[blob_y == g].std(axis=0).mean()
def gap(Z, g1, g2):
    return np.linalg.norm(Z[blob_y == g1].mean(axis=0) - Z[blob_y == g2].mean(axis=0))
print("spread original:", "  ".join(f"{spread(blob_X, g):.2f}" for g in range(3)),
      "   map:", "  ".join(f"{spread(blob_emb, g):.2f}" for g in range(3)))
print(f"gap A-B vs B-C original: {gap(blob_X, 0, 1):.1f} vs {gap(blob_X, 1, 2):.1f}"
      f"   map: {gap(blob_emb, 0, 1):.1f} vs {gap(blob_emb, 1, 2):.1f}")
    spread original: 0.28  1.96  0.99    map: 3.04  4.48  3.08
gap A-B vs B-C original: 6.3 vs 23.7   map: 31.9 vs 41.1
    Sizes nearly equalized, gaps compressed. Then the pure-noise map (next step) invents clumps. Put the red reading-rules card on the board.

  6. Check a map with numbers (3m). "Of each image's 10 true neighbors, how many are map neighbors?" 
    from sklearn.neighbors import NearestNeighbors
from sklearn.manifold import trustworthiness
def neighbors_kept(original, embedded, k=10):
    """Average share of each point's k nearest original neighbors that are also map neighbors."""
    nn_orig = NearestNeighbors(n_neighbors=k + 1).fit(original).kneighbors(original, return_distance=False)[:, 1:]
    nn_emb = NearestNeighbors(n_neighbors=k + 1).fit(embedded).kneighbors(embedded, return_distance=False)[:, 1:]
    return np.mean([len(set(a) & set(b)) / k for a, b in zip(nn_orig, nn_emb)])
for name, emb in [("PCA (2 components)", pca2), ("t-SNE", emb_tsne)]:
    print(f"{name:20s} neighbors kept {neighbors_kept(img50, emb):.3f}"
          f"   trustworthiness {trustworthiness(img50, emb, n_neighbors=10):.3f}")
    PCA (2 components)   neighbors kept 0.235   trustworthiness 0.923
t-SNE                neighbors kept 0.599   trustworthiness 0.988

Three mistakes to expect, and how to coach each
  • Reading sizes and distances. Coach: "Which of the five rules does that sentence break?"
