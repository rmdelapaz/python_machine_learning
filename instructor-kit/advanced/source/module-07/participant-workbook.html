10.1

Neural Networks from Scratch

By the end you can
  • Describe a neuron as a weighted sum plus a bias passed through an activation, and compute one by hand
  • Write the forward pass of a one-hidden-layer network with matrix shapes that line up
  • Explain cross-entropy loss, gradient descent and the learning rate, and implement backpropagation for a small network
  • Check hand-written gradients numerically, and reproduce them with PyTorch's autograd
  • Judge a network honestly against a baseline, logistic regression and gradient boosting on tabular data
Key ideas
  • A neuron is activation(x · w + b). With a sigmoid it is logistic regression.
  • A layer is a matrix multiplication: (n, inputs) @ (inputs, units) → (n, units). Inner dimensions match and disappear. Write the shapes next to the code.
  • Activations bend the boundary. Without them, any number of layers collapses into one straight line. ReLU (slope 1 where active) is the hidden-layer default; the sigmoid sits at the output.
  • Binary cross-entropy measures how wrong the probabilities are; 0.693 is the coin-flip value. A loss stuck there has learned nothing.
  • Gradient descent: parameter -= learning rate × gradient. Too small crawls; too large bounces or explodes. Always look at the loss curve.
  • Backpropagation gets every gradient in one backward sweep (the output error is p - y). A numeric nudge checks it; each gradient has its parameter's shape.
  • Autograd: requires_grad=True, loss.backward(), read .grad. Update under torch.no_grad() and reset .grad every step: gradients add up.
  • Honesty: on the churn table a network beats logistic regression (AUC 0.856 vs 0.823) but not gradient boosting (0.858).
Worked example: XOR with two hidden units

A neural network can do what no straight line can. XOR is the classic case: the output is 1 when exactly one input is 1. Here are two ReLU units with hand-set weights and an output unit, no training at all.

import numpy as np

# Two hidden ReLU units with hand-set weights, then an output unit: XOR, which no straight line can do
W1 = np.array([[1.0, 1.0],
               [1.0, 1.0]])           # (2 inputs, 2 hidden units)
b1 = np.array([0.0, -1.0])
W2 = np.array([[1.0], [-2.0]])      # (2 hidden units, 1 output)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)

hidden = np.maximum(0, X @ W1 + b1)
print(hidden)
print((hidden @ W2).ravel())
[[0. 0.]
 [1. 0.]
 [1. 0.]
 [2. 1.]]
[0. 1. 1. 0.]

The first hidden unit computes x1 + x2; the second computes x1 + x2 - 1, cut at zero, so it is only on for (1, 1). The output takes the first and subtracts twice the second: 0, 1, 1, 0. That is XOR. Each hidden unit drew a line; the output combined them.

from sklearn.linear_model import LogisticRegression
y = np.array([0, 1, 1, 0])
straight = LogisticRegression().fit(X, y)
print("logistic regression predicts:", straight.predict(X), " accuracy", straight.score(X, y))
logistic regression predicts: [0 0 0 0]  accuracy 0.5

Logistic regression, with one straight line, can do no better than chance on these four points (here it predicts 0 everywhere: accuracy 0.5). Training a network means finding weights like the ones above automatically, by gradient descent.

10.2

PyTorch Fundamentals

By the end you can
  • Create and reshape tensors, convert between NumPy and PyTorch, and get the float32 dtype right
  • Define a network with nn.Linear, nn.Sequential and your own nn.Module subclass
  • Choose the loss function that matches the task, and train with an optimizer, a Dataset and a DataLoader
  • Write the standard training loop with model.train(), model.eval(), torch.no_grad(), a validation set and early stopping
  • Save and reload a trained model with state_dict, and judge it honestly against gradient boosting
Key ideas
  • Tensors have a shape, a dtype and a device. Models use float32; NumPy, pandas and scikit-learn give float64: convert with dtype=torch.float32.
  • nn.Module: layers in __init__, wiring in forward; call model(x). nn.Linear(10, 16) stores a (16, 10) weight.
  • Logits out, sigmoid in the loss: BCEWithLogitsLoss (targets float, shape (n, 1)); CrossEntropyLoss for k classes (integer targets, shape (n,)); MSELoss for numbers.
  • The loop: optimizer.zero_grad() → loss = loss_fn(model(xb), yb) → loss.backward() → optimizer.step(), over mini-batches from a shuffled DataLoader.
  • Modes are not gradients: model.train()/model.eval() switch dropout and batch norm; torch.no_grad() switches off tracking. Prediction code uses both.
  • Early stopping keeps a copy.deepcopy of the best state_dict by validation loss and rolls back. The validation score is then optimistic; the test set is scored once.
  • Save state_dict plus the settings and the fitted preprocessing; load with weights_only=True.
  • Honesty again: network 0.846, gradient boosting 0.850 on churn: a tie, and boosting needed none of the choices.
Worked example: the smallest training loop

The smallest possible PyTorch training loop: one nn.Linear(1, 1) rediscovering the rule y = 3x + 2 from 50 points. Every line of the professional loop is here.

import torch
from torch import nn

torch.manual_seed(42)
x = torch.linspace(0, 1, 50).unsqueeze(1)            # (50, 1): one feature, as a column
y = 3 * x + 2                                         # the rule to rediscover
model = nn.Linear(1, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.5)
loss_fn = nn.MSELoss()
for step in range(1, 301):
    optimizer.zero_grad()
    loss = loss_fn(model(x), y)
    loss.backward()
    optimizer.step()
    if step in (1, 10, 100, 300):
        print(f"step {step:3d}  loss {loss.item():.2e}")
print(f"weight {model.weight.item():.3f}  bias {model.bias.item():.3f}")
step   1  loss 5.67e+00
step  10  loss 3.83e-02
step 100  loss 1.11e-07
step 300  loss 2.25e-13
weight 3.000  bias 2.000

The loss collapses toward zero, and the layer's one weight and one bias become 3.000 and 2.000. zero_grad → forward and loss → backward → step: the same four lines train the churn model, the fraud model, and next week's image and sequence models. Only the model, the data and the loss change.

Glossary

TermMeaning
neuron (unit)activation(x · w + b): a weighted sum plus a bias, through an activation
activationThe nonlinear function after the weighted sum: ReLU, sigmoid, tanh
hidden layerA layer between input and output; its width is the number of units
forward passComputing the outputs from the inputs
lossOne number for how wrong the model is; binary cross-entropy for yes/no targets
gradientThe slopes of the loss with respect to every parameter
learning rateThe step size of gradient descent
backpropagationComputing every gradient in one backward sweep with the chain rule
autogradPyTorch's automatic gradients: requires_grad, backward(), .grad
epoch / batchOne pass over the training data / the rows used for one update step
tensorPyTorch's array: shape, dtype, device; can track gradients
logitA raw score before the sigmoid or softmax
optimizerThe object that updates the parameters: SGD, Adam
early stoppingStop when the validation loss stops improving; restore the best weights
state_dictA dictionary of a model's named weight tensors: what you save and load
dropoutRandomly zeroing hidden units while training (switched off by eval())
