Session 13: Capstone Studio II and Showcase

Answers and reasoning for Session 13: the warm-up, the twelve self-check items, the predict-then-run items, the capstone labs' reference outputs (including the review handout's honest numbers), the lesson's quiz and the exit ticket.

Session 13 12 self-check items Confidential

Warm-up

W1
Why does the fraud harness validate on May, not on shuffled folds?
The model scores future months and the fraud rate drifts; validating on a later month mimics that.
W2
What is the one loop the lesson does not allow?
From the test set back to tuning: once you have looked at the test score, the model is finished.
W3
Name two parts of a model card that a weak card usually lacks.
The baseline on the same test set (with an interval for the model), and limitations specific to the data; also often the out-of-scope uses.
W4
What does "explanations are not causes" mean for your card?
Importance and SHAP describe what the model relies on; words like "causes" or "drives" need a design that supports them (none in this course).
W5
Status: your final candidate, its CV score and the baseline's, in one line.
No single answer. Listen for a candidate chosen on training data, and for anyone who has already looked at the test set: they write that in their card.

13.2 · Capstone Project: self-check

Q1
When may you compute the test score of your capstone?
A) After every choice (features, model, hyperparameters, threshold or list size) is made on the training data, once
B) After each improvement, to see whether it helped
C) Before tuning, to know where you stand
D) Whenever, as long as you report the best one
Why: The test set estimates how the finished model does on new data. Every look you act on turns it into training data. If you peeked, say so in the card.
B is wrong: That is tuning on the test set (Common Mistake 4).
C is wrong: Then the tuning is guided by it.
D is wrong: The best of many looks is luck, not performance.
Q2
What does this print?
import numpy as np
print(np.percentile(np.arange(1, 101), [2.5, 97.5]))
[ 3.475 97.525]
Why: The 2.5th and 97.5th percentiles of 1 to 100, with linear interpolation: 3.475 and 97.525. A bootstrap interval reads the same two percentiles from 1,000 resampled scores.
Q3
June average precision: tuned boosting 0.556, logistic regression 0.539; the paired bootstrap interval of the difference is -0.046 to +0.077. What goes in the card?
A) Boosting is better: 0.556 is higher
B) Logistic regression is better: it is simpler
C) The two cannot be told apart on 64 June frauds; choose on other grounds (simplicity, explainability, cost) and say so
D) Neither beats the baseline
Why: The interval includes 0: the data cannot rank them. The capstone lab's numbers: +0.017 (-0.046 to +0.077). Both are far above the no-model 0.008.
A is wrong: A higher point estimate inside the noise is not evidence.
B is wrong: Possibly the right choice, but not because of these numbers: say the real reason.
D is wrong: Both are around 0.54 against 0.008.
Q4
Demand: resampling store-product ROWS gives a 95% interval of 4.90 to 5.53 units saved; resampling whole WEEKS gives 4.68 to 5.81. Which belongs in the card?
A) The row interval: it uses more data points
B) Neither: intervals are optional
C) The narrower one, whichever it is
D) The week interval: rows in the same week share the same conditions, so they are not independent
Why: Rows within a week move together (season, holidays), so treating 4,896 rows as independent makes the interval too narrow. The capstone lab: 4.68 to 5.81 over 51 weeks.
A is wrong: More rows are not more independent evidence.
B is wrong: The rubric's Evaluation row asks for one.
C is wrong: Choosing the interval by width is choosing by wishful thinking.
Q5
Review triage card, first line of Performance. Which is strongest?
A) The model is 87% accurate
B) On 774 held-out reviews the model finds 87% of the negative reviews (the baseline finds none), at accuracy 0.873 (95% CI 0.85 to 0.895) against 0.745
C) The model uses TF-IDF bigrams and balanced logistic regression
D) More data would improve the model
Why: It leads with the business meaning (complaints found), gives the baseline on the same test set and an interval. Numbers from the model-card lab.
A is wrong: No baseline, no interval, and accuracy is not the costly error.
C is wrong: How it works, not how well.
D is wrong: A non-limitation.
Q6
Your segment with the highest churn (about 32%) uses discounts on half its spending. Which sentence may go in the card?
A) Discounts cause these customers to leave
B) Stop discounting to this segment
C) This segment's model was trained on churn
D) Customers in this segment churned more often (about 32%); the segments describe behavior, not why customers leave
Why: The segments were built without the churn column and checked against it afterwards: a description. A causal claim needs an experiment.
A is wrong: A cause the design cannot support.
B is wrong: A decision built on that cause.
C is wrong: Clustering never saw churn: that is what makes the check fair.
Q7
What does this print? (Errors by subgroup.)
import pandas as pd
err = pd.DataFrame({"store": ["Bend", "Bend", "Boise", "Boise", "Boise"],
                    "abs_error": [2.0, 4.0, 10.0, 0.0, 5.0]})
print(err.groupby("store")["abs_error"].mean().to_dict())
{'Bend': 3.0, 'Boise': 5.0}
Why: Bend: (2 + 4) / 2 = 3.0; Boise: (10 + 0 + 5) / 3 = 5.0. A subgroup table is exactly this, with the baseline's errors beside it.
Q8
Your demand model's MAE is lowest for Snow (5.8 units) and highest for Footwear (12.5). What should the card say?
A) Snow is forecast best
B) Compare each group's error with its baseline and its typical volume: Snow sells about 12 units a week, Footwear about 46
C) Drop Footwear from the model
D) Nothing: subgroup errors are noise
Why: Absolute errors follow volume. Against the per-product mean, both groups improve (Snow 13.3 → 5.8, Footwear 18.7 → 12.5); relative to volume, Snow's error is not the smallest.
A is wrong: Low sales give low absolute errors.
C is wrong: Footwear also improves on the baseline.
D is wrong: The checklist asks for them; read them with their baselines.
Q9
Which figure may go into a public portfolio repository?
A) Hit rate at 10 by customer history length, for the model and the baseline
B) A table of ten customers with their recommended products
C) The twenty worst forecast errors with store and product IDs
D) Customer IDs and fraud scores for June
Why: Aggregates only: no customer-level predictions, IDs or purchase histories leave the notebook (the checklist's privacy item), even with fictional data, because the habit is the point.
B is wrong: Purchase histories are personal data.
C is wrong: Row-level output; fine in the notebook, not published.
D is wrong: Customer-level predictions.
Q10
In Problem E, what should you do with age_group?
A) Add it to the clustering so segments are easier to target
B) Delete it from the data file
C) Keep it out of the clustering, then check whether the segments differ by age
D) Use it to name the segments
Why: The lesson keeps demographic columns out of the clustering and checks afterwards: segments describe behavior, and any age imbalance is visible and reportable.
A is wrong: That builds the segments on a sensitive attribute.
B is wrong: You need it for the check.
D is wrong: Names come from behavior profiles.
Q11
After a final rerun, your card says accuracy 0.877 but the notebook prints 0.873. What is the best fix for good?
A) Change the notebook's seed until it prints 0.877
B) Round both to 0.88
C) Delete the number from the card
D) Write the card from the results (results.json and an f-string), and check every card number against it
Why: The model-card lab does exactly this, and catches a hand-typed number: '0.877'.
A is wrong: That is choosing the seed by the result.
B is wrong: It hides the mismatch.
C is wrong: A card without numbers fails Communication.
Q12
Your three-minute showcase. Which outline fits?
A) The decision and the recommendation, the main number against the baseline with its interval, one specific limitation, pointing at one figure
B) Every model you tried, in order
C) The code, cell by cell
D) The rubric scores you gave yourself
Why: The showcase is the model card spoken aloud: recommendation first, evidence against the baseline, one honest limit. "Do not deploy" with evidence is a full showcase.
B is wrong: That is the log, not the story.
C is wrong: The notebook is the scouting trip.
D is wrong: Self-scoring is for the hand-in.

Predict, then run

P1
Predict the output, then run it.
import numpy as np
scores = np.array([0.9, 0.1, 0.4, 0.8, 0.2, 0.05, 0.3, 0.6, 0.7, 0.15])
held = scores >= np.quantile(scores, 0.8)
print(held.sum(), scores[held].tolist())
2 [0.9, 0.8]
Why: The 80th percentile of the ten scores is 0.72; two scores (0.9 and 0.8) are at or above it. A capacity of 1% is the same idea with 0.99.
P2
Predict the output, then run it.
import numpy as np
diffs = np.array([0.02, -0.01, 0.03, 0.00, 0.05])
print(round(float(diffs.mean()), 3), bool(np.percentile(diffs, 2.5) < 0))
0.018 True
Why: The mean difference is 0.018, but the 2.5th percentile is below 0: an interval that includes zero means the data cannot say which model is better.

Lab Reference Solutions

Capstone lab 3: labs/module-13/l13_2-capstone/bootstrap_ci_starter.py → bootstrap_ci_solution.py

The solution prints:

June: 8,262 payments, 64 frauds; no-model AP 0.008
logistic regression  AP +0.539  95% CI +0.408 to +0.658
tuned boosting       AP +0.556  95% CI +0.423 to +0.668
boosting minus LR    AP +0.017  95% CI -0.046 to +0.077
boosting, top 1%: 35 of 64 frauds held (recall 0.55, 95% CI 0.43 to 0.68)

demand 2025: model MAE 8.19, per-product mean 13.42, saved 5.23 units
95% CI, rows resampled:  4.90 to 5.53  (4,896 rows treated as independent)
95% CI, weeks resampled: 4.68 to 5.81  (51 weeks: the honest unit)

Reading it: with 64 frauds, a single average precision has an interval about 0.25 wide; the paired difference between two good models straddles zero, so the card cannot rank them and should choose on other grounds. The capacity recall (0.55, 0.43 to 0.68) is the number the review team understands. On demand, resampling weeks widens the interval by about half: the honest unit.

Handout: labs/module-13/l13_2-capstone/debug_capstone.py (a classmate's capstone to review)

As shipped it prints:

best learning rate 0.1: test MAE 7.60
baseline (predict the average week): MAE 16.98
MODEL CARD: our forecast beats the baseline by 55%.
  1. A random split of weekly rows (train_test_split on time-ordered data): Data and leakage, Evaluation. Use the template's 2024 / 2025 split.
  2. The actual weekly temperature as a feature: unknown when the order is placed (Data and leakage). Here it changes little, which is itself a finding.
  3. The learning rate chosen on the test set: Evaluation (one look). Choose it with rolling folds on 2024.
  4. A baseline that is too weak (the overall mean, 16.98, instead of the template's per-product mean) and no interval: Evaluation and Communication.

What each mistake is worth, one at a time (same model):

random split, with temperature : 7.60
random split, no temperature   : 7.74
2024 -> 2025, with temperature : 8.31
2024 -> 2025, no temperature   : 8.29
overall-mean baseline on 2025  : 17.13

All four fixed (template split, no actual temperature, learning rate chosen by CV on 2024, the template baseline):

CV MAE by learning rate: {0.03: 12.42, 0.05: 12.06, 0.1: 11.66, 0.2: 11.72, 0.3: 11.83}
learning rate 0.1 (chosen by CV on 2024): 2025 test MAE 8.29

The honest model still beats the honest baseline clearly, by 38% rather than 55%: a better story, because it will hold next year.

Exit Ticket

  1. A metric with its interval next to the baseline on the same test set, in the business's units where possible.
  2. Specific limits: the size of the test set, a group the model serves badly, an input that is unvalidated (3-star reviews, new products, new stores), a quirk (stockout zeros).
  3. The rest of the card; then save with skops, results.json, requirements.txt; Restart and Run All; check card numbers; self-score; submit.

Common Wrong Answers and What They Reveal

  • Q3 A. Reads point estimates without intervals: the most common Evaluation weakness.
  • Q4 A. Thinks more rows means more evidence; ask what the rows have in common.
  • Q8 A. Compares absolute errors across groups of different volume.
  • Q11 A. Seed-shopping: the clearest sign the card is being fitted to the notebook instead of written from it.
