Session 12 12 self-check items Confidential

Warm-up

W1
Why does serve.py rebuild the request frame with the stored training dtypes?
Otherwise a None in a one-row table makes an object column the imputer does not treat as missing: a silently different score (training-serving skew).
W2
Of input drift, data quality, prediction drift and performance, which needs labels?
Only performance (AUC, offer precision), and the labels arrive months later.
W3
Where does the churn threshold 0.25 come from, and what does it assume?
$15 / $60: an offer pays when p × 60 > 15. It assumes calibrated probabilities, which the case study confirmed with TunedThresholdClassifierCV.
W4
In the case study, when is the test set used?
Once, after features, model, hyperparameters and threshold are all chosen.
W5
Your capstone in one sentence: the decision, and the baseline number you must beat.
No single answer. Listen for a decision (not a topic) and a number; anyone without one gets the first visit in the plan clinic.

13.2 · Capstone Project: self-check

Q1
Which first line of a capstone plan names a DECISION, not just a target?
A) Each morning the two-person review team decides which of the day's payments to hold; the model ranks them
B) Predict is_fraud from the transaction columns
C) Build the most accurate fraud model possible
D) Use gradient boosting on transactions.csv
Why: A decision has a user and an action (who holds which payments, how many). From it follow the prediction moment, the capacity (about 1% a day) and the right metric.
B is wrong: A target with no user or action: rubric Framing row 1.
C is wrong: "Most accurate" names no decision and invites accuracy on a rare event.
D is wrong: A method is a choice made late, not a plan.
Q2
The demand order is placed three weeks ahead. Which column must NOT be a feature as it stands?
A) promo (planned weeks ahead)
B) avg_high_temp_f, the actual temperature of the forecast week
C) week_of_year
D) list_price
Why: The week's real temperature is not known when the order is placed. Use something known then (last year's temperature for that week) or leave it out; on this data it adds nothing measurable once the month is in.
A is wrong: Planned promotions are known ahead.
C is wrong: The calendar is always known.
D is wrong: List prices are set in advance.
Q3
What does this print?
import pandas as pd
df = pd.DataFrame({"c": ["a", "a", "b", "b", "b"], "d": [3, 1, 2, 5, 4]}).sort_values(["c", "d"])
print(df.groupby("c").tail(1)["d"].tolist())
[3, 5]
Why: After sorting by c and d, tail(1) keeps the last row of each group: the largest d for a (3) and for b (5). The recommendations template uses the same move to hide each customer's latest purchase.
Q4
Why does the fraud harness validate on May instead of a shuffled 5-fold split of January to May?
A) Shuffled folds are slower
B) May has more fraud
C) The model will score future months, and the fraud rate drifts; validating on a later month mimics that
D) scikit-learn cannot shuffle time stamps
Why: Train on the past, check on the next month: the same rule as the June test. On this data logistic regression scores 0.539 average precision on May.
A is wrong: Speed is not the issue.
B is wrong: May has the LOWEST rate of the five training months (0.76%).
D is wrong: It can; it should not here.
Q5
On recommendations, how should you choose the number of SVD factors k?
A) The k with the best hit rate on the test purchases
B) Always k = 5, as in Lesson 11.2
C) The largest k the laptop can fit
D) The best k on a validation purchase carved from the training rows (each customer's second-to-last)
Why: Choosing on the test item makes the test score optimistic. The validation item gives SVD k = 5 0.285 (k = 3: 0.245, k = 10: 0.248); then the test is used once.
A is wrong: That uses the test set to choose.
B is wrong: A good guess, but a capstone shows its own evidence.
C is wrong: More factors memorize: worse, not better.
Q6
K-Means on the four UNscaled behavior columns gives silhouette 0.545, on scaled columns 0.470. Which segments should you keep?
A) The scaled ones: unscaled distances are dominated by average order value, so the higher number comes from a worse clustering
B) The unscaled ones: a higher silhouette is always better
C) Neither: silhouette below 0.6 means no segments
D) Whichever has more equal cluster sizes
Why: Without scaling, a column in dollars outweighs shares between 0 and 1. The unscaled clusters split mostly on order value (sizes 286, 620, 686, 1616, 2792) and agree poorly with the scaled ones (ARI 0.267). A metric compares like with like only on the same features.
B is wrong: Silhouette is only comparable on the same feature space.
C is wrong: There is no such cut-off; 0.47 is clear structure here.
D is wrong: Size balance is not the goal.
Q7
What does this print? (A per-product-mean baseline.)
import numpy as np
from sklearn.metrics import mean_absolute_error
train_units = {"TNT-1": [10, 20], "SNW-1": [0, 4]}
test_units = [("TNT-1", 18), ("SNW-1", 1)]
means = {k: np.mean(v) for k, v in train_units.items()}
print(mean_absolute_error([u for _, u in test_units], [means[p] for p, _ in test_units]))
2.0
Why: The means are 15 (tent) and 2 (snow). Errors |18 - 15| = 3 and |1 - 2| = 1; the mean absolute error is 2.0.
Q8
Your first pipeline does not beat the baseline in your harness. What does the lesson say to do first?
A) Try a neural network
B) Tune harder
C) Look for a bug (a split, a feature, a leak in reverse) before looking for a better model
D) Report "do not deploy" at once
Why: A leak-free simple pipeline that loses to a per-product average usually has a feature or split problem. Only once that is ruled out is a close result a finding.
A is wrong: A bigger model hides the bug.
B is wrong: Tuning a broken setup tunes the bug.
D is wrong: Maybe later, with evidence; not before checking.
Q9
Review triage drops 3-star reviews from training. What belongs in the plan?
A) Nothing: 3-star reviews are neutral
B) Add them to the positive class
C) Delete 3-star reviews in production too
D) Say what the live system does with them and measure it (how many get flagged as negative)
Why: Production will receive them. On this data the model flags about a fifth of 3-star reviews as negative at 0.5, and two thirds at a high-recall threshold: a behavior to report, not to hide.
A is wrong: "Neutral" is an assumption the model does not share.
B is wrong: That changes the question without saying so.
C is wrong: You cannot choose which reviews customers write.
Q10
When should the "do not deploy" bar be written?
A) After the test score, to explain it
B) Before any modeling, in the plan
C) Only if the model does badly
D) In the model card's last section
Why: A bar chosen after seeing the result can always be met. Written in the plan, it makes "do not deploy" a legitimate, rubric-worthy answer (Framing row, Exemplary).
A is wrong: That is rationalizing.
C is wrong: Then it is never written when it matters.
D is wrong: The card reports it; the plan sets it.
Q11
In June, new accounts are 8% of legitimate payments but about 29% of the payments the fraud model wrongly holds. What does the responsible-ML checklist ask?
A) Name who bears the errors, keep a human review with a fast release path, and report results by account age
B) Remove account_age_days so the model cannot see it
C) Nothing: new accounts really are riskier
D) Lower the threshold until the share matches
Why: Holds are reviewed, not declined, and the burden falls on new customers: say so, design for it, and show the subgroup numbers in the card.
B is wrong: Removing a useful, non-sensitive feature can make every group worse; measure first.
C is wrong: True, and still a cost someone pays: it must be written down.
D is wrong: That changes capacity, not who bears the errors.
Q12
Demand harness inside 2024 (rolling folds): ridge MAE 13.13 against the baseline's 13.92, yet on 2025 ridge scores 11.29 against 13.42. Why is the in-2024 harness so pessimistic?
A) Ridge overfits 2024
B) The test set is easier by chance
C) Each validation block contains months the folds have never seen, so a month effect learned from one year cannot be checked forward inside that year
D) MAE is not a valid metric for rolling folds
Why: With one training year, rolling folds always validate on unseen seasons. The harness still ranks candidates fairly against the same baseline (13.924 vs 13.128); say in the card why its numbers are higher than the test's.
A is wrong: The 2025 score shows it generalizes.
B is wrong: The gap appears for every model the same way.
D is wrong: MAE works for any fold.

Predict, then run

P1
Predict the output, then run it.
import pandas as pd
s = pd.Series([10, 0, 30, 0])
print(s.shift(1).tolist())
[nan, 10.0, 0.0, 30.0]
Why: shift(1) moves every value one row later: row 2 sees row 1's value. The first row has no past: NaN. This is how a lag feature only sees earlier days.
P2
Predict the output, then run it.
import pandas as pd
df = pd.DataFrame({"customer": ["a", "a", "a", "b", "b"], "item": ["x", "y", "z", "x", "w"]})
print(df.groupby("customer").tail(1)["item"].tolist(), len(df.groupby("customer").head(-1)))
['z', 'w'] 3
Why: tail(1) keeps each customer's last row (z for a, w for b): the test items. head(-1) keeps all but the last row of each group: 2 + 1 = 3 training rows.

Worked Example, Explained

Shuffled 5-fold CV ($551) is optimistic because neighboring days leak into training; the time-ordered folds ($659) are pessimistic because early folds train on little history; the one look at 2025 gives $600. The lesson's worked example uses more lag features (lag_14, a 7-day mean, events) and reaches $561.

Reading it: the per product × store mean is a stronger demand baseline than the template's per-product mean, while "same week last year" is WORSE (one noisy week against a yearly average). The keyword rule beats "always positive" on reviews and finds about half the complaints. Random groups give a silhouette near 0: the loyalty tiers (0.079) are barely better than random.

Exit Ticket

  1. A harness sentence names training rows, validation rows and the metric; on time-ordered data validation always comes after training.
  2. Two baselines with numbers on the same split and metric (see lab 1 for the reference values).
  3. Any column that fails the timing test, a label such as an ID, or a sensitive attribute kept out of the model and checked afterwards.

Common Wrong Answers and What They Reveal

  • Q2 A (promo). Confuses "changes week to week" with "unknown in advance". Promotions are planned.
  • Q5 A (test hit rate). The most common capstone flaw on recommendations; Lesson 11.2's teaching curve is on the test set, so say why the capstone must differ.
  • Q6 B. Reads a metric without its feature space.
  • Q12 A ("overfits"). Does not yet see that the harness, not the model, is pessimistic.
