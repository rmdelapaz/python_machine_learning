9.2 · Code

Same data, nearly perpendicular directions

def separation(z, labels):
    """Distance between the two class means, in units of the average within-class std."""
    a, b = z[labels == 0], z[labels == 1]
    return abs(a.mean() - b.mean()) / np.sqrt((a.var() + b.var()) / 2)
print(f"separation on PC1: {separation(toy_pca.transform(toy_X)[:, 0], toy_y):.2f}")
print(f"separation on LD1: {separation(toy_lda.transform(toy_X)[:, 0], toy_y):.2f}")
separation on PC1: 0.05
separation on LD1: 3.32
WHY PCA preserves spread; LDA preserves separability.

9.2 · Settings

Axes, priors, shrinkage

  • n_components at most min(features, classes - 1)
  • explained_variance_ratio_: share of class separation
  • priors: move the threshold, not the ranking
  • Many features, few rows: solver="eigen", shrinkage="auto"

1,000 garments: PCA to 50, then t-SNE

from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
pca50 = PCA(n_components=50, random_state=42).fit(img)
img50 = pca50.transform(img)
tsne = TSNE(n_components=2, perplexity=30, random_state=42)

WHY Footwear, trousers, bags: islands. Shirts, pullovers, coats: mixed, because they look alike. Yours may vary slightly.

9.3 · Reading rules

Five rules for every map

  1. Neighbors are meaningful
  2. Cluster sizes are not
  3. Distances between clusters are not (or only roughly)
  4. Axes have no meaning
  5. Validate clusters in the original data
WATCH Low perplexity invents clumps from pure noise.
