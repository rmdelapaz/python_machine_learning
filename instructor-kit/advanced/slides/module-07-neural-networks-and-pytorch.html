10.1

Neural Networks from Scratch

Forward, loss, backward, update: by hand, then by autograd.

10.1 · Mental model

A panel of junior analysts

  • Each junior reads the raw numbers and writes one score: the hidden layer
  • The senior reads only the juniors' scores: the output layer
  • After each round everyone hears their share of the mistake: backpropagation
  • Each junior draws a line; the senior combines them: a boundary that bends
WHY Four steps that never change in Module 10: forward → loss → backward → update.
10.1 · Code

One neuron

import numpy as np

x = np.array([0.5, -1.2, 2.0])     # one customer: three scaled features
w = np.array([0.8, 0.1, -0.4])     # one weight per feature
b = 0.2                            # the bias

z = x @ w + b
weighted sum z    = -0.320
sigmoid(z)        = 0.421
ReLU(z) = max(0,z) = 0.000
WHY With a sigmoid, one neuron is logistic regression: probability 0.42.
10.1 · Shapes

A layer is a matrix multiplication

  • Input X: (n, 2)
  • X @ W1 + b1: (n, 2) @ (2, 16) → (n, 16), then ReLU
  • a1 @ W2 + b2: (n, 16) @ (16, 1) → (n, 1), then sigmoid
  • Inner dimensions match and disappear; the result takes the outer ones
  • Random start (not zero), spread sqrt(2 / inputs): He initialization
HABIT Most network bugs are shape bugs. Write the shape beside every line.

How wrong is it? Cross-entropy

def bce_loss(p, y, eps=1e-12):
    p = np.clip(p, eps, 1 - eps)               # avoid log(0)
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

p, cache = forward(params, X_train)

10.1 · Backpropagation

Errors flow backwards

  1. Output error: p - y (sigmoid + cross-entropy simplify to this)
  2. Output gradients: a1.T @ dz2, shape (16, 1) like W2
  3. Send the error back through W2.T
  4. ReLU gate: keep it only where z1 > 0
  5. Hidden gradients: X.T @ dz1, shape (2, 16) like W1
WHY Check it: nudge one weight by 1e-6 and measure. backprop -0.02341771 numeric -0.02341771.

10.1 · Common mistakes

Loud ones and quiet ones

  • Weights the wrong way round: ValueError: matmul ... mismatch
  • All weights zero: loss frozen at 0.6931, accuracy 0.500
  • Learning rate far too large: the loss bounces or becomes nan
  • A tracked tensor to NumPy: use .detach() or no_grad()
  • Calling backward() twice on one graph: recompute the loss
WATCH Quiet failures cost more time. Always look at the loss curve.

10.2 · Code

Your own nn.Module

class ChurnNet(nn.Module):
    def __init__(self, n_features, n_hidden=16):
        super().__init__()
        self.hidden = nn.Linear(n_features, n_hidden)
        self.output = nn.Linear(n_hidden, 1)

    def forward(self, x):
        return self.output(torch.relu(self.hidden(x)))
WHY Layers in __init__, wiring in forward, logits out. Call model(x), never model.forward(x).
10.2 · Losses

The last layer and the loss go together

  • Yes or no: 1 logit, BCEWithLogitsLoss, float targets (n, 1)
  • One of k classes: k logits, CrossEntropyLoss, integer targets (n,)
  • A number: 1 value, MSELoss, float targets (n, 1)
  • No sigmoid or softmax inside the model: the loss applies it
  • Probabilities for a report: torch.sigmoid(logits)
WHY loss before one step 0.7570, after 0.7288 after one Adam step.

10.2 · The loop

Every PyTorch project in this course

def train_one_epoch(model, loader, loss_fn, optimizer):
    model.train()                                  # training mode (matters for dropout)
    total_loss, n = 0.0, 0
    for xb, yb in loader:
        optimizer.zero_grad()                      # 1. reset gradients
        loss = loss_fn(model(xb), yb)              # 2. forward pass and loss
        loss.backward()                            # 3. backward pass
        optimizer.step()                           # 4. update
        total_loss += loss.item() * len(yb)
        n += len(yb)
    return total_loss / n                          # average loss over the epoch
KEEP model.eval() + torch.no_grad() to evaluate. Save these in training.py.

10.2 · Common mistakes

Read the message: it names both shapes

  • float64 into a float32 layer: same dtype, but got Double and Float
  • Targets (n,) against outputs (n, 1): Target size ... must be the same
  • A column short: shapes cannot be multiplied (900x9 and 10x64)
  • A sigmoid in the model AND in the loss: no error, a floor of 0.31
  • Loading into another architecture: size mismatch
HABIT Print X.dtype, X.shape and y.shape before the first forward pass.
