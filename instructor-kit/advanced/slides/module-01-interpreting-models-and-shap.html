7.1 · Common mistakes

Read the last line, and the setup

  • Integer columns in a PDP: ValueError ... integer data. Use .astype(float)
  • logreg.coef_ on a pipeline: AttributeError. Use logreg[-1]
  • Importance on training rows: bigger numbers, no error
  • Trusting feature_importances_ for a conclusion
  • "Top driver, so the campaign will work": association is not a lever

7.2

SHAP Values

Why this customer? A fair share for every feature.

7.2 · Mental model

Splitting a team bonus fairly

  • Players = features; the bonus = this prediction minus the base value
  • Let them arrive in every order; credit each with what its arrival adds
  • Average over all orders: the Shapley value
  • base value + shares = this prediction, exactly
UNITS Boosting classifier: everything is in log-odds. Squash only the end points with expit.
7.2 · Code

The library agrees with the loop

import numpy as np

toy_model = lambda rows: np.array([toy_risk(*row) for row in rows])

print(toy_explainer(np.array([[240, 0.45, 0]])).values.round(3))
[[0.35 0.15 0.05]]
WHY By hand: days 0.35, discounts 0.15, app 0.05. The 0.10 interaction bonus is split in half.

7.2 · Predict, then run

What does this print?

import itertools
def score(a, b):
    return 0.1 + (0.4 if a and b else 0.0)    # a bonus only when BOTH are present
shares = {"a": 0.0, "b": 0.0}
for order in itertools.permutations(["a", "b"]):
    present = {"a": 0, "b": 0}
    for name in order:
        before = score(**present)
        present[name] = 1
        shares[name] += (score(**present) - before) / 2
print(shares)
  • Who arrives second, and how often?
  • Is the starting score of 0.1 shared out?
7.2 · Which explainer?

TreeExplainer for trees, PermutationExplainer for anything

  • shap.TreeExplainer(model): tree ensembles, fast and exact
  • shap.PermutationExplainer(fn, background): pipelines, anything
  • The background defines "typical": change it and the shares change
  • A forest gives one explanation per class: sv[0, :, 1]
  • TreeExplainer(pipeline): InvalidModelError
WATCH Print .values.shape before you plot a new model's explanation.
