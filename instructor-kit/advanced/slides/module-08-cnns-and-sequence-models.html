10.3

Convolutional Neural Networks

A stencil and a flashlight.

10.3 · Mental model

A stencil and a flashlight

  • A 3 × 3 filter slides over the image; each position: multiply, add
  • The result is a feature map: bright where the pattern appears
  • Local connectivity: each output looks at a small window
  • Weight sharing: one filter everywhere, 9 weights plus a bias
  • Stack layers: edges → corners and stripes → collars and soles
WHY A dense network flattens 784 pixels and forgets which ones are neighbors.

def make_windows(series, window):
    X = np.stack([series[i:i + window] for i in range(len(series) - window)])
    y = series[window:]
    return X, y

10.4 · Common mistakes

Three silent ones

  • No batch_first=True: (batch, time) read as (time, batch); nothing complains
  • Random split of windows: 8 of 9 test windows fully seen
  • Error in scaled units: 0.222 looks great, means nothing; in dollars it is 702
  • float64 windows: RNN input dtype (torch.float64) does not match
