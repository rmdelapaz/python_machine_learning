8.4

Density-Based Clustering

Crowded places, dark fields, and the lone farmhouse.

8.4 · Mental model

A city at night from a plane

  • Towns are where the lights are packed close; their shapes follow valleys, not circles
  • Dark fields between towns; a lone farmhouse is not a town
  • A cluster = a crowded region; the sparse space = noise, label -1
  • Nobody told you how many towns: the count comes out of the data
WHY K-Means puts every point in a round cluster. Density methods do neither.

8.4 · DBSCAN

Core, border, noise

  1. eps: a radius. Closer than eps = neighbors
  2. min_samples: how many points (itself included) make a crowd
  3. Core: a crowded neighborhood · border: next to a core point
  4. Noise: neither, label -1. Core points within eps chain into one cluster
RULE Scale first: eps is a distance.
8.4 · Code

eps is unforgiving

  • On real data the knee is gentle: sweep around it

8.4 · Three algorithms

DBSCAN, OPTICS, HDBSCAN

  • DBSCAN: eps, min_samples; any shape, one density
  • OPTICS: every eps at once; the reachability plot, clusters are valleys
  • HDBSCAN: keeps clusters stable across densities; mainly min_cluster_size
  • None of them has predict; all label noise -1
USE The practical default: HDBSCAN(min_cluster_size=..., copy=True).

8.5

Gaussian Mixture Models

From labels to probabilities.

8.5 · Mental model

Paint mixed from a few base colors

  • Components: the base colors (Gaussian bell-shaped hills)
  • Weights: how much of the palette each supplied (weights_)
  • Means and covariances: where each sits, its spread and tilt
  • A dab between two colors gets a split answer: information, not indecision
WHY K-Means is close to a special case: round, equal, all-or-nothing.

8.5 · Common mistakes

Read the numbers, not the labels

  • Component numbers are arbitrary: name segments by profile
  • More components than rows: ValueError
  • Ignoring a ConvergenceWarning: check converged_
  • A covariance type too simple for the shapes: converges, wrong
  • Stopping at predict: keep the confidence
WATCH Borderline (low confidence) is not the same as atypical (low density).
