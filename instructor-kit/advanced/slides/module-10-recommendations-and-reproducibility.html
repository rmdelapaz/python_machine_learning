11.2 · Code

Two helpers for every recommender

owned = R.toarray() > 0
test_col = col_of[test.set_index("customer_id").loc[customer_ids, "product_id"]].to_numpy()

def top_k(scores, k=10):
    scores = np.array(scores, dtype=float)      # a copy, so the caller's matrix is untouched
    scores[owned] = -np.inf                     # never recommend what they already have
    return np.argsort(-scores, axis=1)[:, :k]   # column numbers of the k highest scores

def hit_rate(scores, k=10):
    return (top_k(scores, k) == test_col[:, None]).any(axis=1).mean()
WHY Any recommender is a score matrix, a mask and a sort.

11.2 · Common mistakes

Three of four give a number, no error

  • Similarity on the wrong axis: matmul: dimension mismatch. Use R.T
  • No owned-item mask: 14% of slots wasted, HR@10 0.270
  • Ascending sort: HR@10 0.001, below random. Use argsort(-scores)
  • A product launched after the model: KeyError. Fall back to content
WATCH A model that loses to random (0.047) is a bug, not a bad model.

12.1 · Code

A fingerprint, not a file name

import hashlib

def file_sha256(path):
    digest = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(1_000_000), b""):
            digest.update(chunk)
    return digest.hexdigest()

data_hash = file_sha256("data/customers_churn.csv")
print(len(data_hash), "hex characters, starting", data_hash[:16])
64 hex characters, starting ac541c7e8691d33f
WHY Same first 16 characters as the page: the same file.

12.1 · Common mistakes

Three refusals that protect you

  • skops without a list: UntrustedTypesFoundException
  • An old tutorial's ./mlruns: MlflowException: use sqlite
  • A parameter changed inside a run: Changing param values is not allowed
  • The classifier without its pipeline: could not convert string to float
WATCH Silent one: trusted=get_untrusted_types(...) trusts anything.
