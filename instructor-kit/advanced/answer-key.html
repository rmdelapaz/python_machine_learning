Q1
In a scaled logistic regression, days_since_last_order has a coefficient of 0.89. Which sentence is right?
A) One more day without an order raises the churn probability by 0.89
B) The model is 89% sure that recency causes churn
C) One more standard deviation of days without an order multiplies the odds of churn by about 2.4, other features held fixed
D) One more standard deviation of days without an order raises the churn probability by 2.4 points
Why: Coefficients of a scaled logistic regression are changes in log-odds per standard deviation; e^0.89 is about 2.43, an odds ratio. Lesson 7.1 then divides by the scaler's standard deviation (87.2 days) to speak per 30 days: x1.36.
A is wrong: Coefficients act on the log-odds, not the probability, and per standard deviation, not per day.
B is wrong: A coefficient measures association inside the model; it is not a probability and not a causal claim.
D is wrong: Odds ratios multiply odds; they do not add percentage points to a probability.

7.2 · SHAP Values: self-check

Q7
Lab 7.2 B's fraud rule never looks at gift_card. Explained against a typical payment, what Shapley value does gift_card get, and why?
A) A quarter of the total, because the four features share the gap equally
B) 0, because adding it never changes the score in any arrival order
C) A negative value, to balance the interaction bonus
D) It cannot be computed: Shapley values need every feature to matter
Why: A feature's Shapley value is its average contribution over all arrival orders. If its arrival never changes the score, every contribution is 0, so its share is 0 (the "null player" rule). The lab prints gift_card: 0.0.
A is wrong: Equal splits only happen for features that play identical roles; the interaction bonus is split 0.15 / 0.15 between night and new device for that reason.
C is wrong: Shares are not invented to balance anything; they add up to the gap exactly as computed.
D is wrong: Unused features are allowed and simply get 0.

P4
Predict the output, then run it.
import itertools
def score(a, b):
    return 0.1 + (0.4 if a and b else 0.0)    # a bonus only when BOTH are present
shares = {"a": 0.0, "b": 0.0}
for order in itertools.permutations(["a", "b"]):
    present = {"a": 0, "b": 0}
    for name in order:
        before = score(**present)
        present[name] = 1
        shares[name] += (score(**present) - before) / 2
print(shares)
{'a': 0.2, 'b': 0.2}
Why: The bonus appears only when the second feature arrives, and each feature is second in one of the two orders, so each gets half of 0.4. The 0.1 starting score is the base value and is not shared out.

Capstone Choice: What to Look For

A plan paragraph is ready when it names a decision and its user, the prediction moment, the split the template uses, a metric with its business meaning, the baseline number, and a "do not deploy" bar. The most common gaps: no prediction moment (so no leakage test is possible), a metric without a unit ("accuracy" for fraud), and no bar. Coaching notes per problem are in final-assessment.html.

Exit Ticket

  1. Two silent failures: a frame without the training dtypes (caught by the match test on rows with gaps); a broken feed hidden by the imputer (caught by missing rates and PSI); an impossible value (caught by schema limits).
  2. 0.333 (= 20 / 60). Check it on out-of-fold predictions or with TunedThresholdClassifierCV; the rule assumes calibrated probabilities. The lab's best for $20 was 0.31.
  3. A letter, a decision and a number, for example "D: the ten products on each customer's home page; best-seller hit rate 0.209".

Common Wrong Answers and What They Reveal

  • Q1 A ("the encoder ignores it"). Thinks of the pipeline as the front door. Draw the window again: the schema runs first.
  • Q3 A or C. Has not seen the silent skew. Rerun demo Step 10 for them.
  • Q4 B ("retrain"). Treats drift as a verdict. Ask which labels they would retrain on.
  • Q5 B (a negative PSI). Expects the terms to cancel. Each term is a difference times the log of the same ratio: always ≥ 0.
  • Q9 B. Reads a gap without its spread. Ask for the ± numbers every time.
  • Exit ticket 2: "0.333, done". Right number, missing check: the case study's whole point is theory confirmed by data.

Why: tail(1) keeps each customer's last row (z for a, w for b): the test items. head(-1) keeps all but the last row of each group: 2 + 1 = 3 training rows.

Worked Example, Explained

Shuffled 5-fold CV ($551) is optimistic because neighboring days leak into training; the time-ordered folds ($659) are pessimistic because early folds train on little history; the one look at 2025 gives $600. The lesson's worked example uses more lag features (lag_14, a 7-day mean, events) and reaches $561.
