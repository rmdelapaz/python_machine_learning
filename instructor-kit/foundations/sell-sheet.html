Teach Machine Learning Foundations

A ready-to-deliver course that turns learners who use Python and pandas into practitioners who build supervised models they can defend: pipelines, honest evaluation, features, linear models, classic classifiers, trees and boosting, selection and tuning, on one company's data, ending in a final project.

11 sessions × 3 h = 33 h 21 lessons 132 self-check items 362 slides 45 lab pairs

Who It's For

Learners: analysts, developers and data-science graduates who know Python and pandas (the course follows Python Data Science); no machine-learning or statistics background needed. Programs: trainers, bootcamps, colleges, corporate L&D and workforce programs; weekly, twice weekly or intensive.

What Learners Can Do After It

  • Split data the way a model will be used, catch leakage, beat a do-nothing baseline
  • Keep every learned step inside a cross-validated pipeline
  • Set thresholds from business costs; compare and tune linear models, k-NN, Naive Bayes, SVMs, trees, forests and boosting fairly
  • Deliver a churn, demand or fraud project with an honest one-page report

What You Get

For every session (×11)
  • Facilitator guide: 0:00–3:00 agenda, scripted demos with real output, mistakes to expect, what to cut
  • Workbook with a 12-item self-check; answer key; slide deck; new labs
Across the kit
  • Combined print-ready books; 45 lab pairs + 14 find-the-bug handouts, checked by one offline command
  • Environment check, diagnostic, Checkpoint 1, a final project with rubric and reference answers, setup guide, public syllabus

Why Instructors Choose It

  • One fictional dataset: Pinecrest Outfitters' churn, demand, 50,000 payments with rare fraud, reviews; planted leaks; no privacy risk
  • Honest pacing: demo, guided lab and project start in the room; the rest at home
  • Every number is real: all code and outputs were run (scikit-learn 1.9)
  • Free tools, no GPU: Python 3.12+, JupyterLab or VS Code; no accounts or downloads in class
