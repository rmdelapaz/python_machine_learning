4.3

Support Vector Machines

Build the widest street between two neighborhoods.

4.3 · Mental model

The widest street

  • Many straight streets separate the two neighborhoods: pick the widest
  • Only the houses on the curbs decide where it goes: the support vectors
  • Overlap: allow houses on the street, at a price: C
  • Curves: bend the street with a kernel; gamma says how far each house reaches
WHY Small C = wide street = simpler model. The same C as logistic regression's.

4.3 · The kernel trick

A ring no line can split

def add_radius(X):
    return np.column_stack([X, (X ** 2).sum(axis=1)])
linear SVM, test accuracy 0.478
linear SVM on (x, y, x²+y²), test accuracy 1.000
  • Linear SVM on (x, y): 0.478
  • Add x² + y²: a flat plane splits them: 1.000
  • A kernel only needs pairwise similarity
  • It works as if lifted, without building features

4.3 · Probabilities

An SVM scores distances

  • predict_proba does not exist: AttributeError
  • Ranking? decision_function (ROC AUC accepts it)
  • Probabilities? CalibratedClassifierCV(SVC(), ensemble=False)
  • Calibrated: average 0.164 vs a real churn rate of 0.165
  • Skip SVC(probability=True): deprecated
4.3 · Common mistakes

Two loud, two silent

  • Grid key "C": Invalid parameter. Use svc__C
  • predict_proba on an SVM: AttributeError
  • Linear SVM, accuracy 0.835: predicts nobody churns (silent)
  • gamma=10: train 0.996, AUC 0.699, 4,491 support vectors (silent)
WATCH Choose C and gamma by cross-validation, never by the training score.

5.1

Decision Trees

A model you can draw and pin to the wall.

5.1 · Mental model

Trail junction signposts

  • A signpost asks one yes-or-no question about one feature
  • Each answer leads down a trail to the next signpost
  • Every trail ends at a campsite: the share of past walkers who left
  • Training: choose the questions. Predicting: walk the trail, read the sign
WHY Gini: the chance that two customers picked from a node disagree.

5.1 · Controls

Choose the size by cross-validation

for leaf in [1, 25, 50, 200]:
    model = DecisionTreeClassifier(
        min_samples_leaf=leaf, random_state=42)
    auc = cross_val_score(model, X_train, y_train, cv=cv,
                          scoring="roc_auc").mean()
    print(leaf, round(auc, 3))
1 0.663
25 0.831
50 0.848
200 0.828
  • Leaf size: every prediction rests on enough customers
  • 50 per leaf: 58 leaves, CV AUC 0.848
  • Also: max_depth, max_leaf_nodes, ccp_alpha
  • Never by the test set

5.1 · Common mistakes

Trees rarely crash

  • Reporting training accuracy 1.000 (test 0.822, baseline 0.835)
  • Ranking with an unpruned tree: probabilities are only 0 and 1
  • class_names in the wrong order: every leaf mislabeled
  • max_depth=0: InvalidParameterError
  • A zero importance read as "irrelevant"
WATCH Build class names from model.classes_.
