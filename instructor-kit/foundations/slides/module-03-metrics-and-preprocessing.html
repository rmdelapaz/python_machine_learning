1.4

Metrics for Classification and Regression

Who did we catch, who did we bother, what did it cost?

1.4 · Mental model

The smoke alarm

  • An alarm that never goes off is right almost every day. Nobody calls it good
  • Recall: when there is a fire, does it go off?
  • Precision: when it goes off, is there a fire?
  • Threshold: how sensitive to set it, from what each mistake costs
WHY For Pinecrest: a wasted call costs a little, a missed churner costs a lot.

1.4 · Thresholds from costs

Put money on the four cells

def campaign_profit(y_true, flagged):
    y_true, flagged = np.asarray(y_true), np.asarray(flagged)
    tp = ((flagged == 1) & (y_true == 1)).sum()
    return CHURNER_VALUE * tp - OFFER_COST * flagged.sum()

print("contact nobody   ", campaign_profit(y_test, np.zeros(len(y_test), dtype=int)))
print("contact everyone ", campaign_profit(y_test, np.ones(len(y_test), dtype=int)))
print("threshold 0.5    ", campaign_profit(y_test, y_pred))
contact nobody    0
contact everyone  -7620
threshold 0.5     2280
MATH OFFER_COST = 15, CHURNER_VALUE = 60. Break-even probability = 15 / 60 = 0.25.

1.4 · Choosing a metric

Pick the number before you train

  • Balanced classes, equal costs: accuracy
  • Ranking and acting on the top: ROC AUC, plus precision at your capacity
  • Rare positives you care about: average precision, precision and recall
  • Known costs: a profit scorer, threshold tuned on training data
  • Regression: MAE against a naive baseline; RMSE when big misses hurt most
WHY Scorer names: roc_auc, average_precision, f1_macro, neg_mean_absolute_error
1.4 · Common mistakes

Most of them print a believable number

  • AUC from predict: 0.615 instead of 0.823, no error
  • Both probability columns: y should be a 1d array
  • precision_score(y_pred, y_test) is the recall
  • Text labels need pos_label="churned"
  • MAPE on weeks with 0 sales: 1,263,687,238,250,694
WATCH Truth first, prediction second. Scores, not labels, for AUC.

2.1 · Mental model

Mise en place

  • Each kind of ingredient gets its own treatment
  • Gaps → imputer · units → scaler · words → encoder
  • The recipe is LEARNED from the training rows
  • Then applied unchanged to the test rows and every new customer
RULE Same rule as Lesson 1.1's scaler: fit_transform on train, transform on the rest.

2.1 · Ordered categories

Spell the order out

  • OrdinalEncoder(categories=[["Basic", "Silver", "Gold"]]): 0, 1, 2
  • Without categories=: alphabetical, Basic 0, Gold 1, Silver 2
  • No warning: the model now thinks Silver is above Gold
  • No order at all (stores, regions)? One-hot instead
WHY Age groups are ordered, but one-hot lets each group have its own effect.

2.1 · Common mistakes

Errors that arrive with next month's data

  • Found unknown categories: use handle_unknown="ignore"
  • Cannot use median strategy: text needs its own branch
  • Pandas output does not support sparse data
  • pd.get_dummies on new rows: the columns do not match
  • Silent: alphabetical tiers; fit_transform on the test rows
WATCH Check: scaled TEST columns should be close to 0, never exactly 0.
