3.1

Linear and Logistic Regression

A straight line that predicts a number, and the same line bent into a probability.

3.1 · Mental model

The ruler on the scatter plot

  • Lay a ruler across the cloud; each dot's gap to it is a residual
  • Least squares: the position with the smallest sum of squared residuals
  • coef_ = slopes, intercept_ = where the line crosses 0
  • Each coefficient holds the other features constant

Numbers that look fine and mean something else

  • A classifier on a number: an error, or silently one class per count
  • Comparing coefficients in different units
  • Twin columns: arbitrary coefficients, same predictions
  • Trusting the line outside the data

3.2

Regularization and the Bias-Variance Trade-off

Add flexibility, then the one dial that stops it from memorizing noise.

3.2 · Mental model

Three students and a practice exam

  • One rule for everything: consistently wrong (bias)
  • Every answer memorized: different each time (variance)
  • Real patterns, details ignored: the goal
  • Expected error = bias² + variance + noise

3.2 · Ridge

A penalty on big weights

for name, reg in [("least squares", LinearRegression()),
                  ("ridge alpha=0.1", Ridge(alpha=0.1))]:
    m = poly_model(15, reg).fit(X_small, y_small)
    big = np.abs(m[-1].coef_).max()
    mse = mean_squared_error(y_new, m.predict(X_new))
    print(f"{name:16s} largest |weight| {big:7.1f}   test MSE {mse:.3f}")
least squares    largest |weight|  1044.5   test MSE 0.187
ridge alpha=0.1  largest |weight|     1.4   test MSE 0.132
WHY Same features, same 25 points: the penalty makes the model use them gently.
