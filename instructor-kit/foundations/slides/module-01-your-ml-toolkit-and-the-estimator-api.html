0.1 · The workflow

Six steps, one loop

  1. Frame the question: what exactly do we predict, and what does a mistake cost?
  2. Prepare the data: which columns may the model use?
  3. Train a model
  4. Evaluate on held-out data, against a baseline: not good enough? Back to 2
  5. Explain the model
  6. Deploy and monitor it
WHY Most real improvement happens in the loop from Evaluate back to Prepare. Today: steps 1 and 2.

1.1 · The estimator API

Create, fit, then predict or score

  1. Create with settings: DummyClassifier(...); read them with get_params()
  2. fit(X_train, y_train): learns, and returns the model
  3. predict / predict_proba on new rows
  4. score(X_test, y_test): accuracy for classifiers, R² for regressors
WHY Learned during fit = a name ending in an underscore: classes_, coef_, mean_.

1.1 · Rank, then check

Barely better on accuracy, very useful as a ranking

risk = pd.DataFrame({"p": proba[:, 1], "churned": y_test.to_numpy()})
risk["decile"] = pd.qcut(risk["p"].rank(method="first"), 10, labels=range(1, 11))
by_decile = risk.groupby("decile", observed=True)["churned"].mean()
print(by_decile.round(2).tolist())
[0.01, 0.03, 0.04, 0.03, 0.05, 0.09, 0.23, 0.27, 0.32, 0.57]
WHY Riskiest tenth: 57% churned, three times the average. The baseline cannot rank anyone.

1.1 · Common mistakes

Read the last line

  • A Series as X: Expected a 2-dimensional container. Use double brackets
  • A text column: could not convert string to float. Lesson 2.1
  • A gap: Input X contains NaN. Lesson 2.1
  • Re-running the cell that creates the model: NotFittedError
  • fit_transform on the test set: no error at all, and that is the problem
WATCH Accuracy alone is not a verdict: compare with the baseline and look at the ranking.
