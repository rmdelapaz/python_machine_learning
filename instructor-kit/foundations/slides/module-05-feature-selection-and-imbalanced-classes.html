2.4

Feature Selection

Pack light, and do not fool yourself while packing.

2.4 · Mental model

An ultralight backpack

  • Two stoves? One goes home: a redundant feature
  • The camp chair you never sit in: an irrelevant feature
  • The water filter stays, though you use it twice a day
  • Goal: the smallest feature set that keeps the score
WHY Selection buys simpler, cheaper, sturdier models, rarely much accuracy.
2.4 · Three families

Filter, wrapper, embedded

  • Filter: scores each column alone (SelectKBest). Fast; blind to the model and to teamwork
  • Wrapper: tries subsets with the real model (RFECV, forward selection). Slow; sees teamwork
  • Embedded: selects while training (an L1 penalty). One fit; tied to one model type
HABITS Decide with CV · keep selection in the pipeline · smallest set within a tolerance

2.4 · Common mistakes

Silent more often than loud

  • NaN reaches the selector: Input X contains NaN. Impute in the pipeline
  • RFE with a model that has no weights (kNN): ValueError
  • L1 without a scaler: keeps dollars, drops a 0-to-1 column
  • "Dropped" read as "does not matter"
  • Selecting before cross-validation: 80% on noise
WATCH L1 needs solver="liblinear"; the default solver refuses it.

2.5

Imbalanced Classes

When the thing you care about happens less than once in a hundred rows.

2.5 · Mental model

The smoke detector

  • Never beeps: right 364 days a year, and worthless
  • Beeps at toast: catches every fire, gets unplugged
  • Where to sit depends on what each mistake costs
  • RANK (does it put frauds near the top?) · DECIDE (where do we cut?)
PRICE cost = $10 × flagged + $375 × missed

2.5 · Samplers

Four fixes, one place

  • Balanced weights · undersampling · oversampling · SMOTE
  • All about 1,900 flags, recall near 0.7, precision near 0.05
  • Ranking (AUC, AP) the same as the plain model, or slightly worse
  • Samplers go inside an imblearn pipeline: run in fit, skipped in predict
WHY For a linear model they shift scores across 0.5. Move the threshold instead.

2.5 · Strategy

A recipe for rare classes

  1. Stratified split, a pipeline model
  2. Judge the ranking: AP against the base rate, ROC AUC
  3. Not good enough? Better features or models, not rebalancing
  4. Price each kind of mistake
  5. Tune the threshold with CV; check once on the test set

2.5 · Common mistakes

Few errors, many wrong numbers

  • A sampler in a scikit-learn pipeline: TypeError
  • SMOTE first, then CV: AP 0.912. Inside: 0.495
  • The formula on weighted probabilities: flags all 15,000
  • cross_val_score without scoring=: accuracy again
  • SMOTE on a text column: could not convert string to float
WATCH False alarms land on real customers: check who carries them.
