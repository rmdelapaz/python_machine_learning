2.2

Pipelines

One object, every step, the one rule known by heart.

2.2 · Mental model

The coffee machine

  • By hand: grind, weigh, tamp, heat, time the shot. Every step a chance to forget
  • A machine does every step in order, the same way every time
  • A pipeline: transformers in order, one model at the end
  • Same fit and predict as one model: CV, grid search and saving just work
WHY Learn from training data, apply to everything else: the machine knows the rule by heart.
2.2 · Inside

What fit and predict do to each step

  1. fit: every step but the last calls fit_transform and passes its output on
  2. The last step (the model) calls fit
  3. predict: every step but the last calls transform only, with what it learned
  4. The model calls predict or predict_proba
WHY Nothing is ever refitted on the rows you predict. That is why a pipeline cannot leak between rows.

The smallest pipeline

A clever feature: churn rate of your signup date

2.2 · Why pipelines stop leaks

Every learning step inside the folds

  • Learns from y (target encoding, selection, resampling): huge leaks
  • Learns from X (imputer, scaler, encoder): small leaks
  • Learns nothing (a fixed function such as np.log1p): cannot leak
  • You do not need to judge each case: put every step in the pipeline
LIMIT A pipeline separates rows, not columns: cancellation_reason in your list still leaks.

2.2 · Common mistakes

Read the start of the message

  • set_params(C=0.1): Invalid parameter 'C'. Prefix the step name
  • A model before a transformer: All intermediate steps should be transformers
  • A column missing at prediction time: columns are missing
  • A step called my__scaler: __ is the separator
  • make_column_selector on the whole table grabs the leak: 0.937, no error
TIP Unsure of a name? print(list(pipe.get_params()))

2.3

Creating Features

Better questions for the model to ask.

2.3 · Mental model

The interviewer and the calculator

  • A linear model is a fast calculator with a fixed shape: weighted sums, straight lines
  • It cannot say "nothing until 150 days, then a jump"
  • It cannot say "tickets matter, but only without the app"
  • You are the interviewer: a new column is a new question
LOOP Explore train → write a function → pipeline → cross-validate → keep or drop.

2.3 · Code

Five questions as five columns

def add_churn_features(df):
    df = df.copy()
    df["lapsed_150"] = (df["days_since_last_order"] > 150).astype(int)
    df["new_customer"] = (df["tenure_months"] < 6).astype(int)
    df["veteran"] = (df["tenure_months"] > 72).astype(int)
    df["heavy_discount"] = (df["discount_share"] > 0.35).astype(int)
    df["tickets_no_app"] = df["support_tickets_12m"] * (1 - df["app_user"])
    return df
print(add_churn_features(X_train)[new_columns].mean().round(3).tolist())

2.3 · Dates

Months on a circle

demand["month_sin"] = np.sin(2 * np.pi * demand["month"] / 12)
demand["month_cos"] = np.cos(2 * np.pi * demand["month"] / 12)
circle = demand.drop_duplicates("month").set_index("month").sort_index()
circle = circle[["month_sin", "month_cos"]]
def gap(a, b):
    return np.linalg.norm(circle.loc[a] - circle.loc[b])
print(f"Dec to Jan: number gap {12 - 1}, circle gap {gap(12, 1):.2f}")
print(f"Jun to Jul: number gap {7 - 6}, circle gap {gap(6, 7):.2f}")
Dec to Jan: number gap 11, circle gap 0.52
Jun to Jul: number gap 1, circle gap 0.52
WHY Both columns: sine alone gives two different months the same value.

2.3 · Silent leaks

Better scores that are not real

rolling_4        used as the forecast: MAE 12.21
rolling_4_leaky  used as the forecast: MAE 9.28
average from 2024 only   MAE 11.36
average from both years  MAE 9.87
  • rolling_4_leaky: no shift(1), so the window contains the week being predicted
  • Average from both years: half of it is the 2025 answers
  • No error, a better score, useless in production
  • Shift first, then roll; aggregate the training rows only
WATCH Ask: on the day of the forecast, would this number exist?

2.3 · Common mistakes

Two loud, two silent

  • .dt on a date read as text: Can only use .dt accessor
  • Dividing by a column with zeros: Input X contains infinity, later, in the model
  • A rolling window without shift(1): MAE 12.21 → 9.28, fake
  • An aggregate over train and test: 11.36 → 9.87, fake
WATCH Choose thresholds and averages from the training rows only.
