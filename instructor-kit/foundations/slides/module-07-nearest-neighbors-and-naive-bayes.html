4.1 · Common mistakes

Distances go wrong quietly

  • No scaler: the largest units decide
  • More neighbors than rows: ValueError
  • Gaps: Input X contains NaN. Impute in the pipeline
  • A tiny k: ties at the top of the ranking
  • Lookalikes searched with an unscaled row

4.2

Naive Bayes

Counting and one rule from probability.

4.2 · Mental model

The seasoned store manager

  • A hunch before reading: the prior
  • Each clue multiplies the odds: "returned" down, "love" up
  • The judgment after reading: the posterior
  • The naive habit: weigh each word on its own
RULE posterior odds = prior odds × likelihood ratio × ...

4.2 · Common mistakes

The wrong variant for the input

  • Raw text into the model: could not convert string to float
  • A scaler before MultinomialNB: Negative values
  • Word counts into GaussianNB: Sparse data was passed
  • alpha=0: vetoes and a divide-by-zero warning
  • Stop words that delete "not"
