## Third-party data and models
Kit A uses **only the Pinecrest Outfitters data**, which is the author's own fictional dataset
(generated by `make_ml_data.py`; no real customers, companies or people). It does **not** use
Fashion-MNIST, EuroSAT or any pretrained network: those public image datasets and model weights appear
only in the Advanced Machine Learning kit, which carries its own notes on them. Nothing in this kit
downloads third-party data.

The open-source software the course installs (Python, NumPy, pandas, Matplotlib, scikit-learn,
XGBoost, LightGBM, imbalanced-learn, Optuna, JupyterLab and the other packages in `requirements.txt`)
is not part of the kit. Each learner installs it from its usual source under its own open-source
license.
