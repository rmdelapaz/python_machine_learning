Your ML Toolkit

By the end you can
  • Create a project folder with a virtual environment, install the course packages, and confirm that scikit-learn and PyTorch import
  • Choose between a notebook and a script for a task, and run code in both
  • Describe the machine-learning workflow (frame, prepare, train, evaluate, explain, deploy) in your own words
  • Tell supervised from unsupervised learning and classification from regression, and name the features and target of a table
  • Load the seven Pinecrest data files and summarize each one's size, gaps and target
Key ideas
  • A workshop of your own. Python is the building, the virtual environment is your workshop, the packages are the tools, the data folder is the raw material. A model is a tool you make by showing it examples.
  • Activation is per terminal window. No (.venv) in the prompt means the computer-wide Python: ModuleNotFoundError. python -m pip installs into the Python you are running.
  • Notebook to explore, script to keep. Running notebook cells out of order is worse in machine learning: a model trained on an old split and graded on a new one gives a meaningless score. Restart and run all when in doubt.
  • The workflow: frame → prepare → train → evaluate → explain → deploy, with a loop from evaluate back to prepare. Most real improvement happens in that loop.
  • Features and a target. The target is the column you predict (churned); features are the columns the model may use. Supervised learning has a target column; unsupervised learning (finding groups) does not.
  • Classification or regression? A category target (churned, fraud) means classification; a quantity (units sold, dollars) means regression. Ask: would a value halfway between two others make sense?
  • Rare classes make accuracy easy to fake. 16.5% of customers churn and 0.88% of payments are fraud, so "nobody churns" is 83.5% accurate and "nothing is fraud" 99.12%.
  • Ask why a value is missing. A gap can be an unfilled form, a signal in itself, a normal day, or a column written after the outcome (a leak).
Worked example: what does a zero mean?

Pinecrest's store managers keep asking about daily sales. Before anyone predicts anything, look at what one row is and what the zeros mean.

import pandas as pd
sales = pd.read_csv("data/daily_store_sales.csv", parse_dates=["date"])
print(sales.shape)
print(sales.head(3))
(4384, 6)
        date      store    sales  transactions  promo event
0 2023-01-01  Asheville  4838.69            69      0   NaN
1 2023-01-01       Bend  4533.55            65      0   NaN
2 2023-01-01      Boise  6026.92            80      0   NaN

One row is one store on one day: 1,096 days × 4 stores = 4,384 rows. The target a forecaster would predict is sales, a quantity: regression.

print(sales["event"].value_counts())
print("days with sales of 0:", (sales["sales"] == 0).sum())
event
Holiday rush         72
Memorial Day sale    48
Labor Day sale       48
Black Friday         48
Closed               24
Name: count, dtype: int64
days with sales of 0: 24

Exactly 24 days have sales of 0, and exactly 24 rows say Closed (Thanksgiving and Christmas, three years, four stores). These zeros are real, not missing: a model must expect them. And most rows have no event at all: that gap simply means "an ordinary day". Always ask what a value, or its absence, means.

1.1

The scikit-learn Estimator API

By the end you can
  • Turn a table into a feature matrix X and a target y, and hold out a test set with train_test_split
  • Use the estimator methods fit, predict, predict_proba and score, and read learned attributes such as coef_
  • Use a transformer with fit and transform, fitting it on the training data only
  • Measure a DummyClassifier baseline and judge whether a real model beats it
  • Swap one model for another without changing the rest of your code
Key ideas
  • The new hire and the case files. fit = study the old files; predict = answer fresh files with the ending torn off; score = the manager's grade. Grade only with files the new hire has never seen.
  • X and y. X is a table (two dimensions, even with one feature: double brackets); y is one column. Today only numeric columns without gaps.
  • train_test_split(X, y, test_size=0.25, stratify=y, random_state=42) keeps a quarter for testing, the same churn share on both sides, and the same rows every time. Results come back as X parts, then y parts.
  • Every estimator: create with settings (get_params()), fit (returns the estimator), then predict, predict_proba or score (accuracy for classifiers, R² for regressors). Names ending in _ were learned during fit.
  • Transformers use fit and transform. Fit the scaler on the training rows only, then transform both sets. set_output(transform="pandas") keeps the column names.
  • A baseline first. DummyClassifier(strategy="most_frequent") scores 0.835 on churn while finding nobody. A model earns its place only by beating it.
  • Probabilities rank. predict_proba(X)[:, 1] is the churn probability (column order = classes_). Sorted into deciles, the riskiest tenth churned at 57%: a model barely better on accuracy can be very useful.
  • Swap models, keep the code. Because every model shares the API, one loop can compare a baseline, logistic regression, a tree and a forest.
Worked example: one feature, four new customers

A model on ONE feature, so you can see exactly what fit learned. The question: how does the time since a customer's last order change the predicted churn risk?

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
customers = pd.read_csv("data/customers_churn.csv")
X = customers[["days_since_last_order"]]          # double brackets: a one-column table
y = customers["churned"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, stratify=y, random_state=42)
tree = DecisionTreeClassifier(max_depth=2, random_state=42).fit(X_train, y_train)
print(f"test accuracy: {tree.score(X_test, y_test):.3f}")
test accuracy: 0.842

Now score four customers who are in no file: 10, 120, 200 and 330 days since their last order.

new = pd.DataFrame({"days_since_last_order": [10, 120, 200, 330]})
print(tree.predict(new))
print(tree.predict_proba(new)[:, 1].round(3))
[0 0 0 1]
[0.097 0.097 0.494 0.595]

A depth-2 tree splits the days into four bands and predicts the churn share of each band. Customers who ordered within the last four months or so are at about 10% risk; at 200 days the risk is 49%, and at 330 days 60%. Notice the third customer: a probability of 0.494 is just under 0.5, so predict says 0. That cut-off is a choice, and Lesson 1.4 is about choosing it well.

Glossary

TermMeaning
virtual environmentA project's own Python and packages (.venv), switched on per terminal with the activate command
kernelThe Python process a notebook runs on; it must be the .venv one
sample (row)One example, such as one customer
featureA column the model may use as input; together they form X
target (label)The column to predict, y
supervised / unsupervisedLearning from rows with the right answer / finding structure without one
classification / regressionPredicting a category / predicting a quantity
baselineWhat a model that learns nothing scores; every model is compared with it
estimatorAny scikit-learn object with fit; models and transformers are estimators
transformerAn estimator that changes data with fit and transform (for example StandardScaler)
hyperparameterA setting chosen before fitting, passed to the constructor (max_depth=4)
learned attributeSomething fit computed, named with a trailing underscore (coef_, mean_)
target leakageA feature that would not be known at prediction time, such as cancellation_reason
decileOne tenth of the rows after sorting, here by predicted risk
