Introduction

LIME (Local Interpretable Model-agnostic Explanations) is a technique for explaining individual predictions of any machine learning classifier or regressor. It works by approximating the model locally with an interpretable model, helping us understand why a model made a specific prediction. This is crucial for building trust in ML systems, debugging models, and meeting regulatory requirements for explainable AI.

LIME for Tabular Data

class LIMETabularExplainer:
    """
    LIME explainer for tabular data
    """
    
    def __init__(self, X_train, feature_names, class_names):
        """
        Initialize LIME explainer for tabular data
        """
        self.explainer = lime.lime_tabular.LimeTabularExplainer(
            X_train,
            feature_names=feature_names,
            class_names=class_names,
            verbose=True,
            mode='classification'
        )
        self.feature_names = feature_names
        self.class_names = class_names
        
    def explain_instance(self, model, instance, num_features=10):
        """
        Explain a single prediction
        """
        # Get prediction
        prediction = model.predict([instance])[0]
        probability = model.predict_proba([instance])[0]
        
        # Generate explanation
        exp = self.explainer.explain_instance(
            instance,
            model.predict_proba,
            num_features=num_features
        )
        
        return exp, prediction, probability
    
    def visualize_explanation(self, exp, prediction, probability):
        """
        Visualize LIME explanation
        """
        fig, axes = plt.subplots(1, 2, figsize=(12, 5))
        
        # Get explanation data
        exp_list = exp.as_list()
        features = [x[0] for x in exp_list]
        values = [x[1] for x in exp_list]
        
        # Feature importance plot
        colors = ['green' if x > 0 else 'red' for x in values]
        axes[0].barh(range(len(values)), values, color=colors)
        axes[0].set_yticks(range(len(features)))
        axes[0].set_yticklabels(features, fontsize=9)
        axes[0].set_xlabel('Feature Contribution')
        axes[0].set_title('Local Feature Importance')
        axes[0].axvline(x=0, color='black', linestyle='-', linewidth=0.5)
        
        # Prediction probabilities
        axes[1].bar(self.class_names, probability)
        axes[1].set_xlabel('Class')
        axes[1].set_ylabel('Probability')
        axes[1].set_title(f'Prediction: {self.class_names[prediction]}')
        axes[1].set_ylim([0, 1])
        
        # Add probability values on bars
        for i, (name, prob) in enumerate(zip(self.class_names, probability)):
            axes[1].text(i, prob + 0.01, f'{prob:.3f}', ha='center')
        
        plt.suptitle('LIME Explanation for Individual Prediction', fontsize=14)
        plt.tight_layout()
        plt.show()
        
        return fig

LIME for Complex Models

class ComplexModelExplainer:
    """
    LIME explanations for complex models
    """
    
    def __init__(self):
        self.models = {}
        self.data = None
        
    def prepare_data(self):
        """
        Prepare breast cancer dataset
        """
        # Load data
        data = load_breast_cancer()
        X, y = data.data, data.target
        
        # Scale features
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        
        # Split data
        X_train, X_test, y_train, y_test = train_test_split(
            X_scaled, y, test_size=0.3, random_state=42
        )
        
        self.data = {
            'X_train': X_train,
            'X_test': X_test,
            'y_train': y_train,
            'y_test': y_test,
            'feature_names': data.feature_names,
            'class_names': data.target_names,
            'scaler': scaler
        }
        
        return self.data
    
    def train_models(self):
        """
        Train different complex models
        """
        print("\n" + "=" * 60)
        print("TRAINING COMPLEX MODELS")
        print("=" * 60)
        
        models = {
            'Random Forest': RandomForestClassifier(
                n_estimators=100, 
                max_depth=10,
                random_state=42
            ),
            'Gradient Boosting': GradientBoostingClassifier(
                n_estimators=100,
                learning_rate=0.1,
                random_state=42
            ),
            'Neural Network': MLPClassifier(
                hidden_layer_sizes=(100, 50),
                max_iter=500,
                random_state=42
            )
        }
        
        for name, model in models.items():
            print(f"\nTraining {name}...")
            model.fit(self.data['X_train'], self.data['y_train'])
            score = model.score(self.data['X_test'], self.data['y_test'])
            print(f"  Accuracy: {score:.3f}")
            self.models[name] = model
        
        return self.models
    
    def compare_explanations(self, instance_idx=0):
        """
        Compare LIME explanations across different models
        """
        print("\n" + "=" * 60)
        print("COMPARING EXPLANATIONS ACROSS MODELS")
        print("=" * 60)
        
        # Get test instance
        test_instance = self.data['X_test'][instance_idx]
        true_label = self.data['y_test'][instance_idx]
        
        # Create explainer
        explainer = lime.lime_tabular.LimeTabularExplainer(
            self.data['X_train'],
            feature_names=self.data['feature_names'],
            class_names=self.data['class_names'],
            mode='classification'
        )
        
        # Collect explanations for each model
        explanations = {}
        predictions = {}
        
        for model_name, model in self.models.items():
            # Get explanation
            exp = explainer.explain_instance(
                test_instance,
                model.predict_proba,
                num_features=10
            )
            
            # Store results
            explanations[model_name] = exp.as_list()
            predictions[model_name] = model.predict([test_instance])[0]
        
        # Visualize comparison
        self.visualize_model_comparison(explanations, predictions, true_label)
        
        return explanations
    
    def visualize_model_comparison(self, explanations, predictions, true_label):
        """
        Visualize explanation comparison
        """
        fig, axes = plt.subplots(1, len(self.models), figsize=(15, 6))
        
        for idx, (model_name, exp_list) in enumerate(explanations.items()):
            # Extract features and values
            features = [x[0].split()[0] for x in exp_list[:8]]  # Top 8 features
            values = [x[1] for x in exp_list[:8]]
            
            # Plot
            colors = ['green' if x > 0 else 'red' for x in values]
            axes[idx].barh(range(len(values)), values, color=colors)
            axes[idx].set_yticks(range(len(features)))
            axes[idx].set_yticklabels(features, fontsize=8)
            axes[idx].set_xlabel('Contribution')
            axes[idx].set_title(f'{model_name}\nPred: {self.data["class_names"][predictions[model_name]]}')
            axes[idx].axvline(x=0, color='black', linestyle='-', linewidth=0.5)
        
        plt.suptitle(f'Model Explanations Comparison\nTrue Label: {self.data["class_names"][true_label]}', 
                    fontsize=14)
        plt.tight_layout()
        plt.show()
    
    def stability_analysis(self, instance_idx=0, n_runs=10):
        """
        Analyze stability of LIME explanations
        """
        print("\n" + "=" * 60)
        print("LIME STABILITY ANALYSIS")
        print("=" * 60)
        
        test_instance = self.data['X_test'][instance_idx]
        model = self.models['Random Forest']
        
        # Create explainer
        explainer = lime.lime_tabular.LimeTabularExplainer(
            self.data['X_train'],
            feature_names=self.data['feature_names'],
            class_names=self.data['class_names'],
            mode='classification'
        )
        
        # Run multiple explanations
        all_explanations = []
        
        for run in range(n_runs):
            exp = explainer.explain_instance(
                test_instance,
                model.predict_proba,
                num_features=10
            )
            
            # Convert to dict for easier processing
            exp_dict = {feat.split()[0]: val for feat, val in exp.as_list()}
            all_explanations.append(exp_dict)
        
        # Calculate statistics
        feature_importance_stats = {}
        all_features = set()
        for exp_dict in all_explanations:
            all_features.update(exp_dict.keys())
        
        for feature in all_features:
            importances = [exp.get(feature, 0) for exp in all_explanations]
            feature_importance_stats[feature] = {
                'mean': np.mean(importances),
                'std': np.std(importances),
                'min': np.min(importances),
                'max': np.max(importances)
            }
        
        # Visualize stability
        self.visualize_stability(feature_importance_stats)
        
        return feature_importance_stats
    
    def visualize_stability(self, stats):
        """
        Visualize explanation stability
        """
        # Sort features by mean importance
        sorted_features = sorted(stats.items(), 
                               key=lambda x: abs(x[1]['mean']), 
                               reverse=True)[:10]
        
        features = [f[0] for f in sorted_features]
        means = [f[1]['mean'] for f in sorted_features]
        stds = [f[1]['std'] for f in sorted_features]
        
        # Plot
        fig, axes = plt.subplots(1, 2, figsize=(12, 5))
        
        # Mean importance with error bars
        colors = ['green' if x > 0 else 'red' for x in means]
        axes[0].barh(range(len(means)), means, xerr=stds, 
                    color=colors, alpha=0.7, capsize=3)
        axes[0].set_yticks(range(len(features)))
        axes[0].set_yticklabels(features, fontsize=9)
        axes[0].set_xlabel('Mean Feature Contribution')
        axes[0].set_title('Feature Importance Stability')
        axes[0].axvline(x=0, color='black', linestyle='-', linewidth=0.5)
        
        # Coefficient of variation
        cv = [abs(std/mean) if mean != 0 else 0 
              for mean, std in zip(means, stds)]
        axes[1].barh(range(len(cv)), cv, color='steelblue')
        axes[1].set_yticks(range(len(features)))
        axes[1].set_yticklabels(features, fontsize=9)
        axes[1].set_xlabel('Coefficient of Variation')
        axes[1].set_title('Relative Stability (lower is more stable)')
        
        plt.suptitle('LIME Explanation Stability Analysis', fontsize=14)
        plt.tight_layout()
        plt.show()

class LIMETextExplainer:
    """
    LIME for text classification
    """
    
    def __init__(self):
        self.vectorizer = TfidfVectorizer(max_features=1000, stop_words='english')
        self.model = None
        self.explainer = lime.lime_text.LimeTextExplainer(class_names=['negative', 'positive'])
        
    def prepare_text_data(self):
        """
        Prepare sample text data
        """
        # Sample movie reviews
        texts = [
            "This movie was absolutely fantastic! Great acting and amazing plot.",
            "Terrible film. Waste of time. Poor acting and boring story.",
            "One of the best movies I've ever seen. Highly recommend!",
            "Disappointing. Expected much better. Not worth watching.",
            "Brilliant cinematography and outstanding performances by all actors.",
            "Awful movie. Can't believe I sat through the whole thing.",
            "A masterpiece! Every scene was perfectly crafted.",
            "Boring and predictable. Save your money."
        ]
        
        # Labels: 1 for positive, 0 for negative
        labels = [1, 0, 1, 0, 1, 0, 1, 0]
        
        return texts, labels
    
    def train_text_classifier(self, texts, labels):
        """
        Train a simple text classifier
        """
        print("\n" + "=" * 60)
        print("TRAINING TEXT CLASSIFIER")
        print("=" * 60)
        
        # Create pipeline
        self.model = make_pipeline(
            self.vectorizer,
            RandomForestClassifier(n_estimators=100, random_state=42)
        )
        
        # Train
        self.model.fit(texts, labels)
        print("Text classifier trained!")
        
        return self.model
    
    def explain_text_prediction(self, text):
        """
        Explain a text classification
        """
        print("\n" + "=" * 60)
        print("LIME TEXT EXPLANATION")
        print("=" * 60)
        print(f"\nText: '{text}'")
        
        # Get prediction
        prediction = self.model.predict([text])[0]
        probability = self.model.predict_proba([text])[0]
        
        print(f"Prediction: {'Positive' if prediction == 1 else 'Negative'}")
        print(f"Confidence: {probability[prediction]:.3f}")
        
        # Generate explanation
        exp = self.explainer.explain_instance(
            text,
            self.model.predict_proba,
            num_features=10
        )
        
        # Visualize
        self.visualize_text_explanation(text, exp, prediction)
        
        return exp
    
    def visualize_text_explanation(self, text, exp, prediction):
        """
        Visualize text explanation
        """
        fig, axes = plt.subplots(1, 2, figsize=(14, 6))
        
        # Get explanation
        exp_list = exp.as_list()
        words = [x[0] for x in exp_list]
        weights = [x[1] for x in exp_list]
        
        # Feature importance
        colors = ['green' if prediction == 1 else 'red' if w > 0 else 'red' if prediction == 1 else 'green' 
                  for w in weights]
        axes[0].barh(range(len(weights)), weights, color=colors)
        axes[0].set_yticks(range(len(words)))
        axes[0].set_yticklabels(words)
        axes[0].set_xlabel('Weight')
        axes[0].set_title(f'Word Importance for {"Positive" if prediction == 1 else "Negative"} Prediction')
        axes[0].axvline(x=0, color='black', linestyle='-', linewidth=0.5)
        
        # Highlighted text
        axes[1].axis('off')
        axes[1].set_title('Text with Important Words Highlighted')
        
        # Create highlighted text representation
        text_words = text.lower().split()
        highlighted_text = ""
        
        word_dict = {w.lower(): weight for w, weight in exp_list}
        
        y_position = 0.9
        x_position = 0.05
        
        for word in text_words:
            clean_word = word.strip('.,!?";')
            
            if clean_word in word_dict:
                weight = word_dict[clean_word]
                if abs(weight) > 0.01:  # Only highlight important words
                    if weight > 0:
                        color = 'green' if prediction == 1 else 'red'
                    else:
                        color = 'red' if prediction == 1 else 'green'
                    
                    axes[1].text(x_position, y_position, word + ' ', 
                               fontsize=12, color=color, weight='bold')
                else:
                    axes[1].text(x_position, y_position, word + ' ', 
                               fontsize=12, color='black')
            else:
                axes[1].text(x_position, y_position, word + ' ', 
                           fontsize=12, color='black')
            
            x_position += 0.1
            if x_position > 0.9:
                x_position = 0.05
                y_position -= 0.1
        
        plt.suptitle('LIME Text Classification Explanation', fontsize=14)
        plt.tight_layout()
        plt.show()

Advanced LIME Techniques

flowchart TB A[LIME Extensions] --> B[Anchors] A --> C[SHAP Integration] A --> D[Counterfactuals] B --> B1[Rule-based Explanations] C --> C1[Global Interpretability] D --> D1[What-if Scenarios] E[Best Practices] --> F[Sampling Strategy] E --> G[Kernel Width] E --> H[Feature Selection] style A fill:#e3f2fd style E fill:#fff9c4 
class AdvancedLIMETechniques:
    """
    Advanced LIME techniques and best practices
    """
    
    @staticmethod
    def submodular_pick(data, model, explainer, num_exps=5):
        """
        Select diverse representative explanations using submodular optimization
        """
        print("\n" + "=" * 60)
        print("SUBMODULAR PICK - REPRESENTATIVE EXPLANATIONS")
        print("=" * 60)
        
        # This would use lime.submodular_pick.SubmodularPick
        # For demonstration, we'll show the concept
        
        print("Submodular Pick selects diverse, representative instances")
        print("that together provide good coverage of the model's behavior.")
        print("\nBenefits:")
        print("  - Reduces redundancy in explanations")
        print("  - Provides global understanding from local explanations")
        print("  - Efficiently summarizes model behavior")
        
        # Simulate picking diverse instances
        n_samples = len(data)
        picked_indices = np.random.choice(n_samples, num_exps, replace=False)
        
        return picked_indices
    
    @staticmethod
    def fidelity_analysis(explainer, model, X_test, n_samples=100):
        """
        Analyze fidelity of LIME explanations
        """
        print("\n" + "=" * 60)
        print("FIDELITY ANALYSIS")
        print("=" * 60)
        
        fidelity_scores = []
        
        for i in range(min(n_samples, len(X_test))):
            instance = X_test[i]
            
            # Get LIME explanation
            exp = explainer.explain_instance(
                instance,
                model.predict_proba,
                num_features=10
            )
            
            # Get linear model coefficients
            local_model = exp.local_exp[1]  # For class 1
            intercept = exp.intercept[1]
            
            # Calculate local prediction
            local_pred = intercept
            for feat_idx, coef in local_model:
                local_pred += coef * instance[feat_idx]
            
            # Get actual model prediction
            actual_pred = model.predict_proba([instance])[0, 1]
            
            # Calculate fidelity (how well local model approximates)
            fidelity = 1 - abs(local_pred - actual_pred)
            fidelity_scores.append(fidelity)
        
        # Statistics
        mean_fidelity = np.mean(fidelity_scores)
        std_fidelity = np.std(fidelity_scores)
        
        print(f"Mean Fidelity: {mean_fidelity:.3f}")
        print(f"Std Fidelity: {std_fidelity:.3f}")
        print(f"Min Fidelity: {np.min(fidelity_scores):.3f}")
        print(f"Max Fidelity: {np.max(fidelity_scores):.3f}")
        
        # Visualize
        plt.figure(figsize=(10, 5))
        plt.subplot(1, 2, 1)
        plt.hist(fidelity_scores, bins=20, edgecolor='black', alpha=0.7)
        plt.xlabel('Fidelity Score')
        plt.ylabel('Frequency')
        plt.title('Distribution of Fidelity Scores')
        plt.axvline(mean_fidelity, color='red', linestyle='--', 
                   label=f'Mean: {mean_fidelity:.3f}')
        plt.legend()
        
        plt.subplot(1, 2, 2)
        plt.plot(fidelity_scores, 'o-', alpha=0.5)
        plt.xlabel('Instance Index')
        plt.ylabel('Fidelity Score')
        plt.title('Fidelity Scores by Instance')
        plt.axhline(mean_fidelity, color='red', linestyle='--', alpha=0.5)
        
        plt.suptitle('LIME Explanation Fidelity Analysis')
        plt.tight_layout()
        plt.show()
        
        return fidelity_scores
    
    @staticmethod
    def parameter_sensitivity(X_train, X_test, model, instance_idx=0):
        """
        Analyze sensitivity to LIME parameters
        """
        print("\n" + "=" * 60)
        print("PARAMETER SENSITIVITY ANALYSIS")
        print("=" * 60)
        
        instance = X_test[instance_idx]
        
        # Different parameter settings
        kernel_widths = [0.25, 0.75, 1.0, 3.0]
        num_samples_list = [100, 500, 1000, 5000]
        
        results = {}
        
        # Test different kernel widths
        print("\nTesting kernel widths...")
        for width in kernel_widths:
            explainer = lime.lime_tabular.LimeTabularExplainer(
                X_train,
                kernel_width=width,
                verbose=False
            )
            
            exp = explainer.explain_instance(
                instance,
                model.predict_proba,
                num_features=5
            )
            
            results[f'width_{width}'] = exp.as_list()
        
        # Test different sample sizes
        print("Testing sample sizes...")
        for num_samples in num_samples_list:
            explainer = lime.lime_tabular.LimeTabularExplainer(
                X_train,
                verbose=False
            )
            
            exp = explainer.explain_instance(
                instance,
                model.predict_proba,
                num_features=5,
                num_samples=num_samples
            )
            
            results[f'samples_{num_samples}'] = exp.as_list()
        
        print("\nParameter sensitivity results stored.")
        print("Key insight: LIME explanations can vary with parameters.")
        print("Recommendation: Use multiple runs and average for stability.")
        
        return results

Best Practices

🎯 LIME Best Practices

  • Sample Size: Use sufficient samples (1000-5000) for stable explanations
  • Feature Selection: Limit to interpretable number of features (5-10)
  • Kernel Width: Tune based on data dimensionality and local neighborhood
  • Multiple Runs: Average over multiple runs for stability
  • Validation: Check fidelity of local approximation
  • Domain Knowledge: Interpret explanations in context
  • Combine Methods: Use with SHAP or other techniques for validation
  • Text Data: Preprocess consistently with model training
  • Categorical Features: Handle properly with one-hot encoding
  • Global Understanding: Use submodular pick for representative set

📝 Lesson Summary

🎓 Key Takeaways

  • LIME is model-agnostic: it explains any classifier or regressor by treating it as a black box you can only query.
  • It works locally — perturbing an instance, seeing how predictions change, and fitting a simple interpretable model to that neighborhood.
  • The output is a per-prediction list of feature contributions, ideal for explaining individual decisions to stakeholders.
  • LIME explanations can be unstable and depend on perturbation and neighborhood settings, so validate before trusting them.

❓ Common Questions at This Stage

Does LIME explain the whole model or just one prediction?

Just one prediction. LIME builds a local approximation around a single instance. For global behavior across all data, reach for tools like SHAP summaries or permutation importance.

Why do LIME explanations sometimes change between runs?

LIME samples random perturbations, so results can vary. Increasing the number of samples and fixing a random seed makes explanations more stable and reproducible.

Is LIME's local linear model the same as the real model?

No — it's a faithful approximation only near the point being explained. Don't extrapolate a LIME explanation to other regions of the input space.
